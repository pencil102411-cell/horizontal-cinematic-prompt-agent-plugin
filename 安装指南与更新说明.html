首次安装

安装只需要做一次。请先确认电脑已经安装 Codex，并且在 PowerShell 中运行 codex --version 能看到版本信息。

1

打开 Windows PowerShell

普通方式打开即可，不需要“以管理员身份运行”。

2

添加公开插件市场

复制下面整行命令并回车，Codex 会从 GitHub 拉取插件仓库。

codex plugin marketplace add pencil102411-cell/horizontal-cinematic-prompt-agent-plugin --ref main
3

安装插件

codex plugin add horizontal-cinematic-prompt-agent-v2@hengping-film-tools
4

新建 Codex 任务并调用

打开实际要制作的场次项目，在该项目中新建任务，然后输入：

$horizontal-cinematic-prompt-agent-v2
请读取当前项目的分镜和资产，为这场戏生成 Seedance 2.0 提示词。
安装成功的判断：运行 codex plugin list --json，能找到 horizontal-cinematic-prompt-agent-v2@hengping-film-tools，并显示 installed: true、enabled: true。

更新插件

维护者把新版本推送到 GitHub 后，已安装的电脑需要刷新市场并重新安装。已经打开的任务不会热更新，请在更新后新建任务。

手动更新

依次执行下面两行：

codex plugin marketplace upgrade hengping-film-tools
codex plugin add horizontal-cinematic-prompt-agent-v2@hengping-film-tools

执行完成后，新建 Codex 任务加载新版。

启用自动更新

首次安装完成后，每台电脑再运行一次：

& "$env:USERPROFILE\.codex\.tmp\marketplaces\hengping-film-tools\tools\register-auto-update.ps1"

它会在 Windows 登录时和每天 12:00 检查更新，并在检测到新版后自动安装。

查看更新日志

%LOCALAPPDATA%\Codex\horizontal-cinematic-prompt-agent-v2\update.log

关闭自动更新

& "$env:USERPROFILE\.codex\.tmp\marketplaces\hengping-film-tools\tools\register-auto-update.ps1" -Remove

从 1.3 到 2.0
改了什么

2.0 不是简单改名。它把 1.3 的本地提示词规则整理成可安装、可更新、能按项目调用的完整插件，并补上影响实际成片质量的关键控制层。

安装与维护

从本地工程变成正式插件

1.3 主要依赖复制文件和手动打开规则；2.0 可直接从公开 GitHub 市场安装，支持手动更新和 Windows 自动更新。

影响：同事安装更简单，团队规则更容易保持一致。
工程结构

删除重复兼容文件

移除重复的 CLAUDE.md，统一由 SKILL.md 负责入口、AGENTS.md 负责主规则，再按场景读取需要的模块。

影响：减少规则重复、互相覆盖和后续维护遗漏。
输出结构

画幅与时长退出模板字段

最终交付统一为“固定约束、素材引用、光影设计、时间轴”四个区块。画幅与生成时长由用户在视频模型界面选择，不再占用提示词。

影响：提示词更集中，避免重复模型界面已有的参数。
镜头语言

加入精确焦段控制

每镜只选一个全画幅等效焦距，并同时写清机距、透视压缩或延展、景深和合焦结果。景别不再只写“近景、特写”这类宽泛标签。

影响：人物比例、空间关系和电影感更稳定。
生成组织

按视频条数组织多镜头

一条提示词对应一次 4—15 秒生成。连续镜头累计不超过 15 秒时合并到同一条时间轴；超过 15 秒才在有效叙事或动作切点拆分。

影响：不再机械地“一镜一条”，镜头衔接和生成效率更好。
人物表演

从表情词库升级为表演逻辑

新增人物目标、阻力、代价、策略、触发和潜台词判断；表演按“基线—触发—泄露—控制或选择—终态”落地，并加入景别、时长、倾听和对白反应控制。

影响：减少假哭、瞪眼、连续点头和堆叠微表情等过演。
表演尺度

加入强度与泪态互斥

内部使用 L1—L5 控制表演幅度、T0—T4 控制泪态；同一镜头只保留一种明确泪态，并取消“表演文字必须占一半”的机械配额。

影响：表演强弱更符合剧情，克制戏不会被写成情绪爆发。
动作连续性

动作改为完整动力链

动作描述覆盖起始站位、准备动作、发力、接触、受力、余势和终点状态，并明确左右手、支撑脚、道具和下一镜连续性。

影响：减少瞬移、换手、站位跳变和动作没有结果的问题。
室外环境

天气必须真正作用于画面

风、雨、雪、雾、尘和光照变化需要写出触发、持续与回落，并体现对衣发、皮肤、动作、地面、植被、道具和光影的可见影响。

影响：室外戏不再只是“背景在下雨”，人物与空间会共同响应。
项目正典

完整迁入《风起玲珑骨》资料

插件内置 24 集定稿剧本原始 PDF、24 份逐集文本、451 场索引和人物表演圣经，可按集数、人物、场次和台词线索反查。

影响：人物关系、伤势、剧情阶段和表演尺度有证据可查。
场次记忆

新增项目内的场次记忆

用户可让插件在当前场次根目录建立 场次记忆.md，记录本场反复验证后的站位、动作、表演尺度、资产和连续性要求。

影响：返修经验能延续到本场下一轮，同时不会污染其他项目。
规则裁决

固定约束会为戏剧效果让位

当空间异变、变身、时间冻结或特殊运镜与通用防崩坏约束冲突时，插件会删除具体冲突项并说明原因，避免两套指令互相抵消。

影响：保住需要的特效和镜头设计，同时继续控制无关崩坏。

推荐使用方式

把 Codex 打开在当前场次项目中，让插件读取该场的分镜、资产和已有记忆。插件中的《风起玲珑骨》正典只会在本剧任务中启用。

第一次开始一个场次

$horizontal-cinematic-prompt-agent-v2
请先读取当前项目的分镜和资产，确认缺少什么，然后建立这个场次的记忆文件。

根据生成结果返修

$horizontal-cinematic-prompt-agent-v2
根据我这次生成结果修正提示词，并把只对本场长期有效的站位、动作和表演要求更新到场次记忆。
场次记忆边界：场次记忆.md 只保存在当前场次项目中，不写回插件、不上传 GitHub，也不会带到其他场次。临时尝试和单次失败不应自动写入。

常见问题

先按下面三项检查，通常不需要重新下载整个仓库。

提示“市场已存在” 跳过首次添加命令，直接运行手动更新的两行命令。
更新后规则没变化 关闭当前任务并新建 Codex 任务。已经打开的任务不会热加载新 Skill。
找不到插件 先运行 codex plugin list --json，确认插件 ID、installed 和 enabled 状态。
