安装只需三步

安装和更新都可以直接让 Codex 操作
1 复制 Git 仓库链接

复制上方完整链接。

2 把链接发给 Codex

告诉它：“帮我安装这个插件，并开启自动更新。”

3 在对话中 @ 引用一次

安装成功后，打开任意对话，输入 @ 并选择“横屏影视提示词 Agent 2.0”即可使用。

以后需要更新时，把同一个仓库链接发给 Codex，说“检查并更新这个插件”，Codex 会完成更新；更新后新建对话即可加载新版。

1.3 → 2.0 核心升级

更稳、更准、更适合连续制作
精确焦段逐镜明确焦距、机距、透视与景深，不再只写宽泛景别。
表演升级加入动机、触发、尺度、泪态、倾听与过演控制。
动作连续锁定站位、发力、接触、受力、余势和下一镜终态。
环境反馈风雨雪雾会真实作用于人物、场景、道具与光影。
多镜合并一次 4—15 秒生成可包含连续多镜，减少机械拆条。
项目正典内置《风起玲珑骨》24 集剧本、451 场索引和人物表演圣经。

效果更佳的用法

不要把整集内容混在一个目录里。以“单集单场”为最小制作单位：

建立单集单场项目文件夹
放入本场分镜、资产与调整要求
让插件建立并维护“场次记忆.md”
根据生成结果持续返修提示词
场次记忆只记录本场有效的站位、动作、表演尺度和连续性要求，并且只保存在当前项目里。
推荐开场方式

在单集单场项目中打开 Codex，@ 引用插件，然后让它先读取本场分镜、资产和场次记忆。
