# 室外环境动力 — 风雨雪雾与人物反馈

> 室外戏按需读取。把环境变化写成可见、连续的事件；用户明确的天气、时间和当前状态优先。只描写镜头实际可见的对象与相关层，不为了满足条目凭空增加人物、道具或天气。

## 一、最低交付要求

风、雨、雪、雾、扬尘、日照突变或水汽变化与镜头有关时，写清环境本体与适用的可见作用。以下是可选层，不要求每镜凑齐：

1. **环境本体**：方向、强弱、密度或变化趋势
2. **人物反馈**：人物在画面中且环境能影响可见部位时，选择衣摆/发丝/皮肤/呼吸/眨眼/重心/步态等表现
3. **场景或道具反馈**：选择画面里实际存在的树叶、草木、积水、檐铃、灯笼、帷幔、旗帜、纸张或兵器水痕等，不补画外物件
4. **光影反馈**：反光、阴影软硬、能见度、体积光、色温或亮度变化；只有确实可见时才写

至少给出一项镜头能看见的作用，避免只写“刮风”“下雨”“雪很大”。画面同时容纳多层时，可用两类反馈交代传播因果；面部特写只写可见的水珠、发丝或迎风反应，空镜只写景物，光线稳定时可以保持，不强制色温、亮度或阴影变化。

## 二、因果链写法

按实际事件选用这条因果顺序，不要求每个镜头都出现新的天气起落：

```text
环境触发或持续状态 → 可见传播路径 → 画内对象受力或受湿 → 可见反应 → 持续、稳定或回落状态
```

环境动作示例片段（不是完整视频提示词，使用前须确认这些对象实际在画面中）：

> 一阵侧风从廊外穿过，先压弯庭中竹叶，再掀起玲珑右侧鬓发和外层纱袖；她眯起迎风侧的眼睛，肩线略向左抵住风力。桌上薄纸被吹起一角后压回，灯笼向同一方向摆动两次，风势随即减弱。

这类因果链能让风向、受力方向和动作节奏一致，避免人物、植被和道具各自乱动。

空镜示例片段：夜雨持续落入石阶积水，雨点击开重叠涟漪，檐口水线保持同一方向；已确认的廊灯在水面映出破碎暖光，整体亮度稳定。画面无人物，不追加衣发或生理反应。

## 三、常用环境映射

| 环境 | 人物可见反馈 | 场景/道具反馈 | 光影与材质反馈 |
|------|--------------|---------------|------------------|
| 微风 | 发梢和最外层轻纱小幅同向摆动，呼吸基本不变 | 叶尖、帷幔边缘、香烟轻偏 | 树影缓移，反光变化很小 |
| 阵风 | 发束、披帛、宽袖先后受力，人物眯眼、压低重心或抬手遮挡 | 枝叶成片翻面，旗幡/灯笼产生延迟摆动，尘土沿地面推进 | 云影或遮挡光快速扫过，轮廓光短暂增强/减弱 |
| 小雨 | 睫毛和鬓发逐渐挂水，肩背衣料颜色加深 | 青石出现散点湿痕，檐口连续滴水，水面形成细密涟漪 | 地面反射增强，远景对比度轻降 |
| 暴雨 | 发丝贴脸，衣料吸水增重，人物缩肩、眨眼或逆雨艰难移动 | 积水被雨点击碎，屋檐形成水帘，旗幡沉重甩动 | 能见度下降，逆光雨丝和水雾形成可见光束；避免无来源闪光 |
| 飘雪 | 雪落在发肩，停留与融化按温度和接触表现；足够寒冷时呼气可见，手指僵硬按人物状态决定 | 屋脊、枝条与地面积雪按实际时长缓慢累积，人物经过时才出现连续足印 | 已有积雪产生冷白漫反射，是否抬亮暗部按光源与积雪范围决定 |
| 雾 | 人物远离镜头时轮廓逐层变淡，呼吸与湿冷反应按需出现 | 建筑、树林按距离分层隐没，雾沿地势缓慢流动 | 对比度与饱和度随距离下降，光束只沿真实光源方向出现 |
| 扬尘 | 人物侧脸避尘、屏息或抬袖遮挡，衣角被气流带动 | 沙尘贴地卷行，碎叶和纸屑沿同一路径移动 | 逆光勾出颗粒层，远景偏暖灰并降低清晰度 |

## 四、连续性与镜头尺度

- 同一场戏以已确认的风向、降水方向、地面湿度、积雪厚度和人物湿身/沾尘程度为起点；按时间轴与实际经过时间保持或改变，不让静态参考图覆盖用户指定的当前天气和身体状态
- 环境先作用于迎风/迎雨面，人物衣发与道具遵循相同方向；不同重量的物体允许出现合理延迟
- 雨雪会累积，不能上一镜湿透、下一镜恢复干燥；镜头切换时保留发丝贴附、衣料颜色、脚印和水痕
- 大远景写云层、林海、雨幕、地表和群体受力；中景写衣摆、步态和附近道具；近景/特写写睫毛水珠、皮肤湿度、发丝贴附、呼吸和细小光影
- 每个节拍突出最相关的环境变化，其余反馈简写；连续风雨、法术气流与尘土可以按因果相继发生，不把“一次主要变化”误解为整镜只能有一种天气作用
- 已有资产和环境信息直接沿用，不重复索要；未见图时不声称读到了具体檐口、灯具或植被，按用户提供事实写，必要假设在最终代码块外说明

## 五、时间轴短句模板

```text
[方向/强度]的[风雨雪雾]从[来源]进入或持续在画面中，[可见传播路径]；[实际在画面的对象]出现[受力/受湿/光学反馈]，到段末[持续/稳定/回落状态]。
```

这是按需填充的环境句片段，不是完整交付模板。写完后检查：天气是否通过镜头能看见的雨丝、雪粒、雾层、衣发、地面、道具或光线得到表达；没有被拍到的层可省略，稳定的状态可保持，不为了凑反馈强加变化。
