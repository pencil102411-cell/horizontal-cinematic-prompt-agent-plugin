序-1 丹穴山 日 外
△ 丹穴山，黑色的混沌之气横行，无数被附身的魔兵与凶兽正在袭击魔族百姓，
老魔尊率众对抗，却力有不及，身上逐渐布满伤口和血污。

△ 老魔尊恨其不争，冲着老婆婆砍杀下去，帝鸿下意识想要阻止，却被混沌之
气裹住全身。

下至尊，一统六道……
△ 帝鸿心神不稳，呕出一口鲜血。混沌趁机攻向帝鸿，此时，一红衣之人冲上
来对抗混沌，帝鸿隐约看见是个女子身形。
△ 帝鸿想要追上去看清楚，但往前一扑，场景变幻，战争结束，死伤一片。
△ 帝鸿浑身浴血，手中紧紧攥着一把长剑，而他的身边则是老魔尊的尸体，尸
体上有一道深深的剑痕。
混沌：你杀了你父亲，滋味如何？
△ 混沌叫嚣着，帝鸿惊魂不定。
