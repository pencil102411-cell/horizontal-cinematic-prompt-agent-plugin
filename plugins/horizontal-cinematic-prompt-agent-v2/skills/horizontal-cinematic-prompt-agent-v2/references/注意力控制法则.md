# 注意力控制法则 — 通用六维框架

> 所有 skill 共享的画面注意力组织方法，服务于观众看清人物、动作和信息关系。它是创作工具，不是模型内部注意力配额；不声称能通过文字分配固定百分比。用户要求、人物关系与具体叙事需要优先，不因本框架而停下任务或削弱关键对手。

---

## 六维框架

### 1. 确定当下的观看中心

先明确这一拍让观众关注谁或什么。视觉中心可以是单个人、双人关系、群体动作或环境变化，也可以随信息揭示而转移；通过构图、动作时序、明暗和焦点表达，不写不可验证的注意力百分比。

- 当前关键人物、物件或关系是什么
- 哪些信息要同时清楚，哪些暂时处于背景
- 多角色同框时明确各自位置、动作对象和观众的观看顺序；对峙或配合可有同等重要的双方

**避免：** 用模糊代词、相互矛盾的动作或不明接触关系混写多人。多主体本身不是错误，也不能把画面融合或肢体问题简单归因于双方同等重要。

### 2. 锚定核心动作

一个节拍先突出一个主要动作或信息变化；一个镜头可以连续完成多个有因果的动作与攻防回合。每一拍交代谁发起、谁响应、落点是什么，再承接下一拍，不把“一个核心动作”误读为整镜只能动一次。

- 辅助动作：服务于当前节拍（手部微调、衣摆飘动、重心微移），也可为下一拍埋下可见触发
- 对手的攻击、防守和反应按因果完整表达；不要因为他是次要角色就把力道、目标或落点删掉
- 删除与当前或后续叙事无关的突兀动作，减少误解，不把删动作当作防止形变的万能办法

### 3. 界定画面边界

明确画面里实际存在且能被看见的对象，以及它们如何参与当前事件。无关元素可以简写，相关的环境变化和互动不能为了“主体突出”被抹掉。

| 客体类型 | 约束方式 |
|---------|---------|
| 背景客体（建筑、天空） | 按实际场景保持结构或描写必要变化；天气、坍塌或人群变化承担叙事时可成为观看中心 |
| 互动人物（对手、路人） | 对手保留完整目的、动作幅度与因果反应；路人的活动按与事件的关系安排，不一律弱化 |
| 环境物件（桌椅、道具） | 除叙事需要外不赋予动态 |

### 4. 规划镜头调度

镜头是观众的眼睛，选择运动或固定观察，让关键关系可读。按镜头需要明确：

- 镜头跟谁走、观察何物，或为何保持固定
- 镜头从哪到哪
- 速度如何变化
- 焦点落在哪、何时转移，或哪些对象需要同时清楚
- 主体在画面中的位置（居中/偏左/偏右/前景压住）

**禁止：** "镜头动一动""拉近一点"等模糊指令。

### 5. 设定光影色彩

光影和色彩组织观看与情绪。按实际场景选择需要说明的内容：

- 主体由什么光源照亮（光源必须有物理动机）
- 背景保持明亮、压暗或与人物分层的可见方式；不强制所有场景压暗背景
- 哪些颜色属于主体焦点，哪些只做气氛

### 6. 把控时间节奏

最终视频提示词用时间轴标明必要的状态演变。一条视频可含多个镜头，一个镜头可含多个时间段和节拍；保持、等待与固定观察也可以是有效状态，不必把下列阶段凑齐：

- 哪一秒谁先入画
- 哪一秒镜头开始动
- 哪一秒动作起手
- 哪一秒动作落点完成
- 哪一秒进入回落/余波

已有镜头时长直接求和；未提供时长时沿用 `AGENTS.md` 的 15 秒工作基准并在代码块外说明。时间划分服务台词、动作和情绪节奏，不机械限制整镜动作数量，也不要求每拍都切镜。
