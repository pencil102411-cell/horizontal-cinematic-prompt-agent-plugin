## 一、电影布光系统

### 1.1 核心三原则

- **用明暗组织观看**：先决定观众看哪里，再分配亮部、暗部与负空间；低调照明是默认工具之一，白昼、高调或柔和散射光同样可以有电影感，不必强造死黑
- **光源有动机**：自然、灯具、反射或法术光都要有能解释受光的来源；以已见资产的结构及用户确认的本场状态为依据，未见图时不虚构“图里已有”的灯具和窗位
- **质感源于衰减**：关注光线从亮到暗的过渡区域（roll-off），这是体现质感的关键

### 1.2 布光公式

```
[光比风格] + [主光方位] + [光质] + [动机光源] + [高阶修饰]
```

### 1.3 五大布光方向

| 布光方式 | 视觉特征 | 情绪映射 | 提示词写法 |
|---------|---------|---------|--------|
| 顶光 | 眼窝/颧骨下投射骷髅状死黑阴影 | 神秘、危险、压抑、黑化 | 顶光（top light）自头顶直射，眼窝与颧骨下方投出骷髅状死黑阴影，氛围阴森压抑 |
| 侧光/阴阳光 | 光源90度，脸部一半极亮一半死黑 | 善恶交织、内心冲突、反派揭晓 | 硬质侧光（split lighting）与面部成90度，脸一半极亮一半沉入死黑，高反差阴阳分割 |
| 伦勃朗光 | 背光面脸颊形成倒三角光斑 | 古典油画感、高级、人物性格刻画 | 伦勃朗光（Rembrandt lighting），背光面脸颊浮现倒三角光斑，明暗过渡如古典油画（chiaroscuro） |
| 逆光/轮廓光 | 勾勒头发肩膀高亮金边，人物与背景剥离 | 唯美、史诗、英雄登场、孤独神圣 | 强逆光（backlight），轮廓光（rim light）勾出发丝与肩线的高亮金边，主体从背景中剥离 |
| 底光 | 低处光源向上照亮，面部阴影方向有别于常见天光 | 恐怖、非日常、悬疑惊悚 | 低处已确认的火盆或法术光形成底光（bottom light），自下而上打亮面部，鼻翼与眉骨阴影向上延伸，诡异感来自受光方向 |

### 1.4 光质与光比

**硬光（hard light）**
锐利清晰的阴影，凸显皮肤毛孔、皱纹和粗糙纹理。适合动作戏、悬疑、反派。
> 硬质直射光（hard light），阴影边缘锐利清晰，放大皮肤毛孔与粗糙表面纹理

**柔光（soft light）**
阴影边缘模糊，明暗过渡极其柔和。适合情感戏、仙侠唯美、回忆。
> 高度扩散的柔光（soft light），阴影边缘模糊，明暗过渡平滑（soft roll-off），面部受光柔和

**低调照明/明暗法（low-key / chiaroscuro）**
画面大部分是暗部，只对关键部位选择性照明。适合隐藏信息、压迫或静默关系；是否采用取决于场面，不将它作为电影感的唯一标准。
> 低调照明（low-key），明暗法（chiaroscuro），画面八成沉入暗部，只对关键部位选择性照明，暗部保留层次不死黑

**高调照明（high-key）**
画面明亮均匀，几乎无阴影。适合梦境、回忆、轻喜剧。
> 高调照明（high-key），曝光均匀，几乎不见阴影，明亮通透如梦境

### 1.5 动机光源（古装/仙侠场景常用）

| 场景 | 动机光源 | 提示词写法 |
|------|---------|------------|
| 夜间室内 | 烛火、灯笼、香炉火光 | 烛火摇曳的暖黄光（candlelight）／灯笼暖光晕染（lantern glow） |
| 月夜户外 | 月光 | 冷调月光（moonlight）透过枝叶洒落，在地面碎成斑驳光点 |
| 修炼/法术 | 灵气光晕、丹炉火焰 | 灵气光晕自体内透出（spiritual glow）／丹炉火光自下方摇曳打亮（furnace fire） |
| 黄昏 | 夕阳逆光 | 夕阳低角度逆光（golden hour backlight），边缘镀上炽烈金边 |
| 林间 | 林隙阳光 | 林隙光柱穿透树冠（god rays），丁达尔效应（Tyndall effect）可见 |

### 1.6 高阶光学修饰

**遮光投影（gobo）**
光线穿过百叶窗、树枝、铁栅在人物脸上投射几何阴影，极大增加画面故事性。
> 光线穿过窗棂、枯枝或铁栅，在人物脸上投下锐利的几何硬阴影（gobo lighting）

**体积光/丁达尔效应（volumetric light）**
光与烟雾、灰尘、雨水发生物理反应，形成实体光柱。
> 体积光（volumetric light），丁达尔效应（Tyndall effect），光柱穿过烟尘与水汽形成可见的实体光束（god rays）

### 2.2 焦段、机距与透视

焦距不能只写一个毫米数。普通镜头使用一个精确的全画幅等效焦距，并交代摄影机距离、透视关系与景深的可见结果；明确设计镜内变焦时允许起止焦距，写清主体大小、背景范围与对焦如何变化。透视主要取决于机位与主体距离，焦距用于安排取景；不要把“长焦必压缩、广角必畸变”写成脱离机位的绝对规律。

**本项目默认审美仍是人物中景及更近景别优先 85mm 以上。** 下表提供常用选择，不封死焦段。需要表现贴身空间、主观压迫、环境与人物同时清晰、狭窄机位或明确的变焦效果时，可以选择更合适的焦距，必要时在代码块外简述其画面作用；用户已明确指定时直接执行，不额外索取许可。

| 景别 | 默认可选焦距 | 应按本镜实际情况写出的可见结果 |
|------|---------|------------------|
| 大远景 / 远景 / 大全景 | 24mm / 28mm / 32mm / 35mm | 靠近前景时呈现近大远小与纵深展开；远机位时按实际层次写，不凭焦距强造近前景；景深按叙事需要选择 |
| 全景 | 65mm；常用于全身关系或空间轴线 | 中等机距下人物比例自然、空间轻度压缩，人物与关键场景层次可辨；更广或更长焦的全景也可按具体意图设计 |
| 中景 / 中近景 | 85mm / 100mm | 较远机距保持构图时，背景相对放大、前后层次趋于压缩；默认浅景深，但双人关系或空间信息需要时可扩大清晰范围 |
| 近景 / 特写 / 大特写 / 插入 | 100mm / 135mm | 默认用较远机位和浅景深突出脸、手或物件；明确关键部位及背景虚化结果。插入镜头的机距与合焦对象按物件实际尺度安排 |

**写法约束：**

- 普通镜头只选一个精确值，不把范围、斜杠、`或`、`任选`留给生成模型决策；镜内变焦使用明确起止值，属于有方向的变化，不是备选范围
- 用户明确指定焦距时优先遵从，但仍补足对应的机距、透视和景深结果
- 全景不因为“拍到全身”就自动使用广角；根据机位、主体与环境的关系选焦距，广角也可用于有明确叙事作用的近距离镜头
- 中景及更近景别默认使用 85mm 以上；景深按信息需要决定。双人同等重要、动作纵深或明确的焦点交接不强制单一人物始终清晰，也不为遵守浅景深而丢掉关键动作
- 焦距用于表达创作意图；机身、T 光圈、帧率、快门角度、ISO、白平衡等默认转成可见结果。实际生成入口有对应控制且用户需要时，按其界面设置，不以提示词数字保证精确执行

**合格示例：**

> 中近景，100mm长焦定焦；摄影机远离玲珑，背景相对放大并靠近她的肩线，前后景明显压缩；很浅景深，双眼清晰，背景只保留虚化灯点与暗木色块。

**镜内变焦示例片段：**

> 玲珑近景起幅，焦距从 100mm 连续缩至 50mm，摄影机保持原位，玲珑在画面中逐渐缩小，两侧原本出画的门框与逼近的人影进入取景；人物与背景的透视关系保持不变，焦点仍落在玲珑双眼。较广的终点焦距用于揭示被包围的空间。

### 2.3 推拉运镜

| 运镜 | 情绪效果 | 提示词写法 |
|------|---------|----------|
| 慢速推入 | 步步紧逼、心理转折点 | 缓慢推入（slow dolly in），焦点逐渐收拢到主体双眼，心理压力层层升高 |
| 快速拉出 | 被遗弃感、打破舒适区 | 摄影机快速后撤（fast dolly out），焦距保持本镜设定，主体在画面中缩小，前后景视差变化，周围空间逐渐显露 |
| 快速变焦拉远 | 突然揭示包围关系或空间信息 | 摄影机原位快速变焦拉远（fast zoom out），使用本镜指定的起止焦距，主体缩小、取景变宽，透视关系不因机位改变 |
| 眩晕变焦 | 精神失常、极度恐惧、幻觉 | 眩晕变焦（dolly zoom），摄影机移动与焦距变化反向配合；写明起止焦距和机位方向，主体画面大小近似不变，背景相对尺度与透视随机距产生拉伸或压缩 |

### 2.4 轴向与空间运镜

| 运镜 | 适用场景 | 提示词写法 |
|------|---------|----------|
| Z轴纵深 | 贯穿场景、纵深感 | 沿纵深轴推进（Z-axis movement），隧道式视野，前后景拉出强烈视差（parallax） |
| FPV第一人称 | 追逐、飞行、极速穿梭 | 第一人称飞行视角（FPV drone shot），高速穿梭，背景带运动模糊（motion blur） |
| 环绕运镜 | 被包围、展示立体空间 | 环绕运镜（orbit shot），绕主体作360度旋转 |
| 低角度仰拍 | 英雄登场、压迫感、仰视大法相 | 低角度仰拍（low angle / worm's-eye view），主体显得高大而具压迫感 |
| 越肩跟拍 | 追逐、动量连续、对峙 | 越肩跟拍（over-the-shoulder tracking），动量连续不断 |
| 手持震动 | 紧张、混乱、真实感 | 手持镜头（handheld），带轻微呼吸感的自然抖动，纪实真实感 |

### 2.5 延时摄影（timelapse）

适用场景：时间流逝、空间过渡、修行漫长感、战斗后的世界恢复。

```
[云层高速流动] + [光影在地面的快速位移] + [角色在画面中保持静止或极慢动作]
```

**两种模式：**

| 模式 | 描述 | 提示词写法 |
|------|------|--------|
| 静止延时 | 机位固定，环境高速变化（云流/日夜交替/季节转换），角色静止 | 固定机位延时（static timelapse），云层高速流过天空，日影在地面快速扫移，角色始终静止于画面中央，时间被极度压缩 |
| 运动延时 | 机位缓慢推进/拉远的同时延时，环境与镜头双重变化 | 运动延时（hyperlapse），镜头缓慢推进的同时环境高速变化，光轨拖曳成线，角色只有极微小的可见动作 |

**古装适用要点：**
- 延时主体可以是：打坐修炼、等待、伤后昏迷苏醒、战斗后烟尘落定
- 环境变化元素替换为：香炉烟迹加速飘散/烛火快速燃烧/树影在窗纸上的快速位移/云雾在山间的高速翻涌
- 常用做法是角色保持静止或完成一个极慢动作（缓缓睁眼/慢慢起身），与环境形成动静对比；剧情需要连续动作时按节拍展开，空镜不补角色

### 2.6 情绪-运镜-布光组合示例

**古装英雄登场（史诗感）**
> 低角度仰拍（low angle），强逆光轮廓光（rim light）勾出发光剪影，体积光（volumetric light）穿透战场烟尘

**情感对话（压抑/克制）**
> 缓慢推入面部（slow dolly in），伦勃朗光（Rembrandt lighting），柔光平滑过渡（soft roll-off），内在张力持续上升

**人物内心崩溃（恐惧/失控）**
> 眩晕变焦（dolly zoom）令背景扭曲，顶光（top light）在眼窝投下骷髅状阴影，低调照明（low-key）压死暗部

**追逐/动作戏（速度感）**
> 第一人称视角（FPV），硬质侧光（hard side light），运动模糊只作用于背景（motion blur on background only），速度感扑面

## 三、材质叙事学

**材质写法：用适用的物理痕迹与光学反应表现触感和经历。** 不为“质感”给完好的新衣、武器或玉石强加战损；已有资产的形制与当前已确认状态优先，未被看到或确认的划痕、汗渍和缺口只可作为明确的创作设定。

| 类型 | 弃用写法 | 复用写法 |
|------|---------|---------|
| 金属 | 闪亮的剑 | 带划痕的古铜，覆有汗渍的剑柄，刃口有轻微缺口 |
| 布料 | 好看的长袍 | 带重力坠感的宋锦，腰封边缘有轻微磨砂，袖口有细小使用折痕 |
| 皮革 | 皮甲 | 带细小压痕和边缘磨损的皮革，金属扣件哑光氧化 |
| 玉石 | 玉佩 | 温润半透的白玉，内部有轻微棉絮感，边缘有自然光晕 |

**通用材质质感词：**
> 材质纹理丰富（textural richness），画面带细微颗粒感（film grain），表面微观纹理清晰可辨，留有真实使用痕迹与物理侵蚀（physical erosion）

## 五、世界电影风格精选（古装/武侠适用）

从 37 种世界电影风格中精选 5 种与古装/武侠/仙侠兼容的风格，作为画面基调注入词。

### 5.1 张艺谋色彩美学
- **特征**：极端饱和度的单一主色调统治画面、大面积纯色布景、色彩作为叙事符号
- **适用**：大场面仪式、攻城战、宫廷戏、意境空镜
- **提示词写法**：张艺谋式色彩美学，单一高饱和主色统治全画面，大面积色块构图，色彩本身承担叙事

### 5.2 王家卫情绪视觉
- **特征**：拖影步态、霓虹/暖黄与深绿对冲、浅景深面部特写、慢速步态镜头
- **适用**：情感戏、回忆/闪回、雨夜街巷、孤独角色
- **提示词写法**：王家卫式情绪影像，人物移动拖出绵长残影，浅景深亲密特写，暖琥珀与深绿在画面中对冲

### 5.3 黑泽明武士史诗
- **特征**：强侧光/暴雨环境、群体几何站位、极简构图、动静极端切换
- **适用**：竹林/雨中对决、军团对峙、英雄孤独登场
- **提示词写法**：黑泽明式武士史诗，暴雨与狂风的极端天气，群体呈几何阵列站位，构图极简，高反差黑白或低饱和色调

### 5.4 塔可夫斯基诗意长镜头
- **特征**：极慢运镜、自然元素（水/火/草/风）的超长时间凝视、时间如雕塑般可触
- **适用**：修炼感悟、战后余波、角色内心独白时刻、自然空镜
- **提示词写法**：塔可夫斯基式诗意长镜，极慢的沉思式镜头漂移，水火草风等自然元素被长时间凝视，时间质感可触

### 5.5 赛博仙侠融合
- **特征**：古装服饰/古建与全息光效/能量光路/悬浮法阵的融合、冷金属与暖灵气色彩对冲
- **适用**：修仙世界观中"科技感宗门"/"灵气机械文明"场景
- **提示词写法**：赛博仙侠融合，古装丝袍缀有全息光纹，古塔建筑外悬浮光阵，灵气可视化为流动光路，冷金属与暖灵气色彩对冲

### 风格使用守则
- 默认选一种主导基调，保持同场色彩、材质和镜头体验连贯；用户明确要求融合或场面需要风格转变时，写清各特征承担什么作用及如何衔接，避免仅堆多个风格名称
- 风格名称 + 1-2 个视觉特征词即可注入提示词，不堆叠全量风格描述
- 风格是"滤镜"而非"主体"——主体永远是角色动作和叙事，风格起情绪放大器作用
