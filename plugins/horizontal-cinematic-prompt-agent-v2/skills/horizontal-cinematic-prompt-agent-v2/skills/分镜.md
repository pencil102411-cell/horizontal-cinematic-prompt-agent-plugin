# 分镜 Skill — 横屏真人影视

> 适用模型：Seedance 2.0 及同类视频生成模型
> 适用类型：横屏真人古装 / 仙侠 / 武侠短剧
> 核心目标：用导演视角设计镜头序列，每一镜都服务于信息、情绪、人物关系或动作节拍的变化
>
> **写法约定**：最终提示词使用中文主干；运镜、布光、材质、VFX 四类专业术语按需附「中文（English keyword）」。本文件示例是设计片段，需要按当前资产、人物、时长和镜头目的适配，不作为完整提示词直接照抄。
>
> **适用边界**：优先级与交付方式遵循 `AGENTS.md`。用户当前明确要求和已确认场次条件高于默认与示例；已有分镜按其方案生成，发现具体的时值、空间或动作问题时指出影响并给最小建议，不擅自重排镜头。

## 参考标尺

三组电影视觉系统，用于校准镜头判断：

- **《绝命毒师》** → 静止镜头力量、负空间、构图压迫、听者反应、节奏呼吸
- **《满江红》** → 低饱和、高级灰、封闭空间压力、弱暖光、暗部层次
- **《凡人修仙传》** → 文戏克制、武戏动作链条、特效前摇与余波、比例反差

## 0. 输入自适应

本 Skill 接收三种输入，自动切换处理深度：

| 输入类型 | 处理方式 |
|---------|---------|
| 单镜头需求 | 直接定起幅→展开→落点 + 运镜 + 风险规避 |
| 单场戏 | 先判断场戏核心，再建立空间轴线，最后拆镜 |
| 多场戏/剧本片段 | 先自动切场（依据：空间变化/时间变化/人物组合变化/冲突对象变化/情绪阶段变化），再逐场拆镜 |

> 生成最终视频提示词时，拆镜结果并入 `templates/标准输出模板.md` 四区块中的【时间轴】，不额外重复交付分镜表。用户当前要求分析、讨论或镜头建议时直接完成该项任务，不强套四区块。

**信息不足时的处理：** 非关键缺口先做合理导演判断并在代码块外标注，不索要完整表单。画幅由用户在模型界面选择，不写进提示词；未说明风格时默认低饱和、克制、电影感。已有逐镜时长先求和；既无总时长也无逐镜时长时，默认按15秒工作基准编排并在代码块外说明，不仅因缺时长停下。

**时间单位与镜头选择：** 一条提示词对应一次视频生成；一条视频可以有多个镜头，一个连续镜头也可以按时间段描述多个动作节拍。时间段边界不自动等于切镜点；连续攻防、反应与焦点交接只要因果清楚就可留在同镜。焦距与景深默认、叙事例外和变焦写法见 `references/镜头与灯光词典.md` §2.2。

室外戏拆镜时把天气变化当作叙事动作：先确定风雨雪雾的触发与方向，再安排它对人物、场景/道具和光影的可见反馈。不能把天气只放在开场空镜，后续人物镜头却完全不受影响；细则见 `references/室外环境动力.md`。

## 1. 总控原则

### 1.1 分镜不是逐句配图

不要看到一句台词就切一个镜头。切镜前先判断：

- 这一刻观众需要看到什么新信息？
- 情绪有没有升级、转向或停顿？
- 人物关系有没有变化？
- 画面重点是否从"人"转向"动作 / 道具 / 证据 / 空间结果"？
- 这一刀切过去是否比不切更有效？

**答不上来就不要切。长镜头优于无意义切镜。**

### 1.2 无效切镜识别

以下情况都是无效切镜，必须避免：

- 上一镜和下一镜信息差不多
- 景别变了，但情绪没有推进
- 只是为了"有变化"而换角度
- 为了正反打而硬切正反打
- 为了套"全景 → 中景 → 近景 → 特写"公式而切
- 一句台词一镜头，导致镜头碎但没有导演逻辑

### 1.3 景别跳跃规则

"跳景别"的目的是避免相邻镜头太相似，让观众明确感到画面重点改变了。但它不是死规则：

- 双人中景 → 单人近景：重点从人物关系变成情绪反应
- 单人近景 → 手部/道具特写：重点从人物变成证据或关键物件
- 近景 → 远景：重点从个人情绪变成空间结果或命运状态
- 中景 → 中景可以成立，前提是机位、视角、人物关系或情绪重心明显变化
- 连续两个差不多的中景：应该删除一个或重新设计切镜理由

**真正的规则不是必须跳景别，而是不能无效切镜。**

### 1.4 镜头要有明确作用

在内部判断每个镜头承担的信息、情绪、关系或动作作用，最终提示词写成可见构图和行为。例如不只写“中景，A在左，B在右”，而写“A在左侧前倾逼近，B守住右侧位置、肩线收紧”。道具证据或空间镜头不必强加人物情绪。

| 镜头方式 | 常见情绪作用 |
|---------|------------|
| 平视双人中景 | 建立关系、对峙、空间清楚 |
| 略低角度拍强势者 | 压迫、威胁、权力上位 |
| 略高角度拍弱势者 | 羞辱、无助、被审视 |
| 侧面近景 | 动作方向清楚，适合耳光、推搡、拔剑 |
| 单人近景 | 情绪反应、表情变化、心理压力 |
| 局部特写 | 证据、痛感、道具、关键动作 |
| 背面远景 / 纵深远景 | 孤立、离开、被带走、命运落定 |
| 过肩镜头 | 对话压力、视线关系、正反打 |

## 2. 正反打规则

### 2.1 正反打仅在以下情况使用

- 对话双方有明确攻防关系
- 一方施压，另一方承受
- 观众需要看说话者和听话者的反应
- 角色之间的权力关系、情绪变化需要通过视线来表达

不要为了"看起来专业"硬做正反打。

### 2.2 正反打要有清楚的轴线与视线关系

关系镜是建立轴线的默认方法；已有镜头、场次条件或清楚的视线线索已经交代关系时，不重复添加建立镜。设计时先明确：

- 谁在左，谁在右
- 两人面对方向
- 谁强势，谁弱势
- 空间关系是否清楚

**之后保持可理解的视线与方向关系。** 调度、环绕或有意越轴可以改变画面左右，但须写清过渡与新位置，不能无因跳变。

### 2.3 正反打结构参考（按当前节拍选用）

1. **关系镜** — 交代双方站位和权力关系
2. **正打强势者** — 看施压、质问、攻击
3. **反打弱势者** — 看承受、退缩、解释、沉默
4. **关键细节** — 手、道具、证据、伤口、动作
5. **回到关系镜** — 看结果、命令、距离变化或权力落定

## 3. 对话戏拆分方法

### 3.1 判断情绪驱动者

有时候说话的人不是最重要的，听话人的反应才是重点：

- A在骂人，B被羞辱但忍住 → 重点可能是B
- A说出秘密，B的震惊反应才是镜头重点
- A平静说话但话语在压迫B → 切B的反应
- 两人真正交锋时 → 才适合正反打来回切

### 3.2 台词合并与拆分

| 判断 | 处理 |
|------|------|
| 台词只是继续同一种压迫 | 合并，不切 |
| 台词造成新的反应 | 应该切 |
| 台词带来证据、动作或转折 | 应该切 |
| 台词从质问变成宣判 | 应该切 |
| 台词从解释变成求饶 | 应该切 |

### 3.3 对话戏机位选择

参照 [references/镜头与灯光词典.md](../references/镜头与灯光词典.md) 中情绪-运镜-布光组合：

- **压抑/克制**：慢速推入 + 伦勃朗光 + 柔光
- **对峙/压迫**：越肩跟拍 + 侧光硬光
- **崩溃/爆发**：中近景 + 手持轻微抖动 + 顶光
- **柔情/亲密**：固定机位 + 柔光 + 逆光轮廓

## 4. 动作戏拆分方法

### 4.1 动作链法则

动作戏不能只写结果，必须写动作链条：

```
起手 → 发力 → 接触 → 结果
```

- ✅ "他蹬地发力，身体冲出，手伸向她，抓住她手腕，两人落地"
- ❌ "他飞身救下她"

### 4.2 动作镜头常用结构

下列是因果节点，不是强制四镜或四段；同一镜头可以完整呈现一组动作，也可以接续数个攻防回合。

1. 准备/起手
2. 发力/冲击
3. 接触/高潮
4. 结果/反应

### 4.3 动作戏机位选择

| 动作类型 | 推荐机位 |
|---------|---------|
| 单人突进 | 略低角度 + 越肩跟拍 |
| 受击/被压制 | 略高角度 + 受击跟随 |
| 双人对攻 | 侧面镜头 + 中景跟随 |
| 群攻/包围 | 广角全景 + 环绕运镜 |
| 轻功/飞行 | FPV + 低角度仰拍 |

详见 [skills/动作戏.md](动作戏.md) 镜头调度字典。

## 5. 景别选择规则

### 5.1 大远景 / 远景

用于：交代空间、人物渺小、孤立/离开/命运感、多人站位或空间压迫

不要滥用在普通对话里。

### 5.2 全景 / 中全景

用于：建立人物站位、看清两人距离、身体姿态、建立基本空间关系

适合开场关系镜。

### 5.3 中景

用于：对话、冲突中的身体姿态、角色之间权力关系、一方指责一方退缩、动作和台词同时需要被看清

中景是对话戏主力，但不能连续滥用。

### 5.4 中近景 / 近景

用于：情绪靠近、角色解释/忍耐/求饶/压迫、看清上半身和表情、正反打中的单人镜头

### 5.5 特写

用于：关键表情、伤口/手/道具/证据、一句话造成的心理冲击、情绪爆发点

**特写要珍惜，不能乱给。** 没有"视觉证据"或"强情绪变化"时不要硬切。

### 5.6 大特写

用于极强强调：眼睛、嘴唇、手指、关键物件一小部分

**大特写必须有强烈叙事理由。**

## 6. 机位与角度规则

| 机位 | 作用 | 拍谁 |
|------|------|------|
| 平视 | 客观、稳定、建立关系 | 普通对话、空间说明 |
| 略低角度 | 压迫、威胁、权力上位 | 强势者、审问者、攻击者 |
| 略高角度 | 羞辱、无助、被审视 | 弱势者、受害者、求饶者 |
| 侧面镜头 | 动作方向清楚 | 耳光、推搡、拔剑、转身离开 |
| 过肩镜头 | 对话压力、视线关系 | 正反打、攻防关系 |

### 6.1 POV第一人称子系统

POV（Point of View）不是一种"运镜"，而是将观众置入角色视觉感知系统的摄法。每种 POV 对应不同的信息策略和约束。

**四种 POV 类型：**

| POV 类型 | 视觉特征 | 叙事功能 | 约束 |
|---------|---------|---------|------|
| **纯视觉 POV** | 镜头=角色眼睛所见，含眨眼/视线模糊/血流视野等生理反馈 | 观众完全代入角色感知，适合被突袭、中毒幻觉、濒死体验 | 只出现该视点实际能看见的部位：手、脚、低头可见的身体或明确镜面中的脸；不能无因看见自己的外部正面全身 |
| **越肩 POV** | 镜头在角色肩后，角色头/肩在前景，观者与角色朝向一致 | 带入角色立场，适合对话压迫、对峙、观察场景 | 前景角色只能出现后脑/肩部轮廓，不能遮蔽画面重点 |
| **半主观 POV** | 镜头在角色近侧（脸旁/耳边），角色半脸入画，随其呼吸微晃 | 共情但不完全代入，适合犹豫、暗中观察、战术判断 | 角色面部只能侧入画，不能正对镜头 |
| **全主观幻想 POV** | 角色"想象/回忆/幻觉"的所见，可带失真/色彩偏移/叠影等非常规视觉 | 传达角色的内在心理状态，适合闪回、噩梦、精神污染 | 按叙事需要用视觉、声音或前后信息提示层次；刻意延迟揭示幻觉时，不强加异常滤镜 |

**POV 使用建议：**
- 默认在关键感知或情绪节点使用，不设固定比例；明确的全主观场面可以全程使用
- 切换不同人物的 POV 时写清观看者、朝向与视线目标；关系不清时可返回客观镜头，已有线索足够时不强加过渡
- 纯视觉 POV 与越肩镜头可按观看—反应关系交替，检查机位、方向和主体比例是否接得上
- 首次 POV 可用客观反打交代“谁在看”；也可由手部、声线、已知站位或前后镜头建立身份，悬疑需求可延后揭示
- 区分角色眼睛所见的 POV 与外部飞行跟拍（FPV drone shot），不要同一句同时写“角色第一人称”与“跟在该角色身后”

**POV 提示词速查**（中文主干，术语附英文）：

- **纯视觉 POV**（first-person POV）：镜头即角色双眼所见，按需要表现眨眼或余光模糊；呼气白雾可短暂进入下方视野，不把角色双眼写成会被呼吸呵湿的镜片
- **越肩 POV**（over-the-shoulder POV）：角色肩部与后脑在前景，观众与角色朝向一致
- **半主观 POV**（intimate side-angle POV）：角色侧脸在画面边缘，镜头随其呼吸轻微起伏
- **全主观幻想 POV**（subjective reality POV）：色彩偏移失真，画面带记忆残影叠加，梦境逻辑

## 7. 类型场景分镜策略

### 7.1 对话/对峙场景

- 判断情绪驱动者 → 建立轴线 → 正反打结构
- 镜头节奏：慢、稳，以情绪变化为切镜依据
- 参照：本文件对话戏拆分 + [skills/情感表演.md](情感表演.md)

### 7.2 动作/打斗场景

- 动作链必须完整（起手→发力→接触→结果）
- 每个动作节拍明确视觉锚点（主攻者/受击者/追逐目标/双人攻防关系），同镜转换时写清交接
- 15秒动作请求可参考四段：0-3起势 / 3-8爆发 / 8-12变招 / 12-15收束；其他时长按实际节拍重排
- 参照：本文件动作戏拆分 + [skills/动作戏.md](动作戏.md)

### 7.3 特效/法术场景

- 以蓄力→爆发→奇观展开→收束检查因果，按当前内容决定是否包含全部阶段，不强制四镜四段
- 同镜可有相连阶段或多个协同效果，明确主次与作用关系，去掉无关奇观
- 需要保留主体时让身份与动作可读；消散、变身或遮挡阶段按设定允许轮廓变化，并写清起止锚点
- 参照：[skills/特效戏.md](特效戏.md)

### 7.4 情绪/表演场景

- 面部可读且情绪由视线驱动时优先写眼神；开场也可从背影、手上任务、道具或空间进入，不强制眼睛特写
- 辅助动作从属核心情绪变化
- 参照：[skills/情感表演.md](情感表演.md) + [references/镜头与灯光词典.md](../references/镜头与灯光词典.md)

### 7.5 节奏曲线设计

需要设计镜头时，可先在内部理清一条节奏线；已有分镜则沿用其结构检查承接，不强套完整起伏：

> 铺垫 → 压迫/靠近 → 停顿/留白 → 转折/爆发 → 余波/收束

- **文戏**：慢压为主，局部停顿蓄力，爆发点克制但精确
- **武戏**：慢蓄力→快发力→命中停顿→反馈爆发→余震回落
- **特效戏**：微观前摇→空间异动→比例反差→爆发→余波空镜

每个镜头应承担明确的叙事作用。如果多个镜头都处在同一节点（如“一直压迫”），检查是否仍有信息或关系变化；持续压迫、持续静止或进行中结尾有明确目的时可以保留。

### 7.6 空镜与转场规则

空镜不是风景装饰，只能承担以下功能之一：

- 承接人物心理（刚被抛弃的角色离开后的空椅子）
- 传递空间压力（封闭走廊、高墙、窄巷）
- 暗示关系变化（桌上未被拿走的信物）
- 制造情绪余波（战斗后缓慢落下的碎屑）
- 为下一轮爆发蓄力（暴风雨前的寂静水面）
- 时间或场景转换（光线穿过灰尘的过渡）

按空镜所处位置核对其空间、信息、情绪或转场作用：开场可以建立环境，独立素材可以展示所需状态，结尾可以承载余波，不要求同时具备前后镜。已有前后镜时再核对衔接；无明确作用时提出精简建议，不自动删除用户已确认的镜头。

**转场方式速查：**

| 转场 | 情绪功能 |
|------|---------|
| 硬切 | 节奏紧凑、冲突升级 |
| 渐变/淡入淡出 | 情绪过渡、时间流逝 |
| 叠化 | 回忆、梦境、双重时空 |
| 黑场 | 场景终结、重大转折 |

### 7.7 短剧感风险排查

输出前逐项检查以下"短剧通病"：

- [ ] 是否一句台词一镜？
- [ ] 开场特写是否有明确作用；需要空间信息时是否已有足够线索？
- [ ] 正反打的轴线与视线是否清楚，是否机械补了已有信息的关系镜？
- [ ] 是否空镜无效（无功能、纯装饰）？
- [ ] 是否情绪过满（所有镜头都100%强度）？
- [ ] 是否运镜炫技（镜头动但信息没变）？
- [ ] 是否动作/特效缺少前摇和余波？
- [ ] 是否节奏无呼吸（全程平或全程炸）？

## 8. 子弹时间变速法（进阶附录）

子弹时间不只是一句 `bullet time` 描述词，而是一种变速结构。

### 8.1 变速节奏公式

```
正常速度(铺垫) → 极端慢动作(子弹时间聚焦点) → 正常速度(结果)
```

**核心**：子弹时间的美学力量来自于"极快动作被极端慢放"——先建立高速预期，再用升格打破预期。

### 8.2 四种子弹时间应用场景

| 场景 | 子弹时间聚焦 | 慢到什么程度（写进提示词的说法） | 持续时间 |
|------|------------|--------------------------|---------|
| 兵刃碰撞瞬间 | 剑刃接触点火花迸发 | 火星逐颗可辨，能看清每一粒的飞行轨迹 | 1-2秒 |
| 致命一击 | 武器命中前一寸的悬停感 | 武器停在离面门一寸处，刃口反光的移动清晰可见 | 2-3秒 |
| 多人合击同时爆发 | 多个命中点同时展开 | 几个命中点的冲击几乎同时凝住，衣料褶皱缓慢展开 | 2-4秒 |
| 角色穿越粒子/碎片/水滴 | 碎片悬浮定格，角色穿行其中 | 碎片近乎静止悬在空中，只有角色以可察觉的速度移动 | 3-5秒 |

> **不写「20-30x升格」这类倍率。** 模型没有帧率控制接口，倍率数字进了提示词就是无效 token，白占字数预算。一律用上表右侧那种「能看清什么」的视觉描述——表达等价，且模型真的能执行。

### 8.3 提示词变量模板

```
[正常速度段 0-Xs]：
[角色动作]以真实速度进行，[环境反馈]同步全速运动。

[子弹时间段 X-Ys]：
画面渐变进入极慢速（bullet time），速度过渡连续不突变。
[聚焦对象]悬停在动作中途：[详细描述被冻结的瞬间状态]。
[角色]在凝住的[碎片/水滴/火花]之间穿行，是画面里唯一以可察觉速度移动的元素。
每一粒[碎片/火花/水滴]都单独可辨、边缘锐利，悬在半空。

[恢复正常段 Y-15s]：
慢速释放，所有悬停元素同时完成各自的轨迹，[结果描述]。
```

### 8.4 使用建议

- 默认少量使用，把慢动作留给重要信息；需要反复变速的招式结构可以多次使用，不设固定次数上限
- 写清升格与正常速度的衔接；连续变速可用变速过渡（speed ramp transition），刻意硬切速度则明确切点与视觉结果
- 焦点可为兵刃、身体动作、面部反应、碎屑、液体或火花，只要慢放能显露必要信息，不为填前景强加粒子
- 普通慢动作中人物与环境遵守同一时间变化；只有本场明确存在超常时间差时，才使用上例“人物穿行、碎片近乎冻结”的写法
- 与 `skills/动作戏.md` 模式B 配合时，可在蓄力、命中或变招点使用子弹时间，高速残影留给需要展示高速路径的节拍

## 9. 镜头卡格式（设计阶段内部工作稿）

> **默认作为内部工作稿。** 本节镜头卡用于理清每一镜的作用、切镜理由、站位与时值；用户要求查看设计分析时可展示，不能用它替代用户要的最终视频提示词。
>
> 交付给用户的最终提示词**一律走 `templates/标准输出模板.md` 的四区块格式**（固定约束 / 素材引用 / 光影设计 / 时间轴）。镜头卡里的景别、精确焦距、景深、机位、运镜、站位、情绪，全部并入四区块中的【时间轴】各段。

设计阶段每个镜头按以下结构理清：

```
镜头X：[此镜作用，如：建立压迫关系]

景别：[全景 / 中景 / 近景 / 特写]
焦距：[精确全画幅等效焦距 + 镜头类别 + 摄影机距离/透视结果；明确变焦镜头写起止焦距、连续变化与可见结果]
焦点/景深：[景深等级 + 当前焦点对象与可见虚化结果；焦点转移时写起止对象、触发与前后清晰关系]
机位：[平视 / 略低角度 / 略高角度 / 侧面 / 过肩 / 低仰 / 跟拍]
镜头情绪：[这一镜要传达的情绪]
人物站位：[谁在左，谁在右，谁在前景，谁在后景]
画面重点：[这一镜观众必须看懂什么]
运镜方式：[固定 / 推入 / 拉出 / 环绕 / 越肩 / 手持]
时长：[秒]
本镜要点：[本镜适用且不可遗漏的信息：景别、焦距与可见景深、机位和固定/运镜、主体事件；情绪、环境反馈和灯光变化按实际可见内容填写，不为凑齐字段加人、加动作或改变构图]
```

### 输出示例（对峙场景）

```
镜头1：建立压迫关系

景别：中景
焦距：100mm长焦定焦；摄影机远离两人，背景相对放大靠近，前后景压缩
焦点/景深：浅景深，两人面部处在同一合焦平面，背景暗木结构局部虚化
机位：平视
镜头情绪：压迫与弱势对峙
人物站位：管事左前，杨夕右后，管事身体前倾，杨夕低头缩肩
画面重点：管事居高临下训斥，杨夕不敢反驳
运镜方式：固定机位
时长：3秒
本镜要点：固定中景，平视。管事在画面左侧身体前倾、手指向右侧，杨夕在画面右侧低头缩肩、双手收在身前，一压一退的对峙关系。伦勃朗光（Rembrandt lighting），柔光过渡。
```

### 台词时值参考

分镜"时长"列的计算依据。按台词字数和语速估算镜头时长：

**标点不计入字数。**

| 语速 | 换算 | 示例 |
|------|------|------|
| 慢速 | 1秒2字 → 每字0.5s | "你在怕什么"（5字）→ 约2.5秒 |
| 中速 | 1秒3字 → 每字≈0.33s | "你到底想怎么样"（7字）→ 约2.5秒 |
| 快速 | 1秒4字 → 每字0.25s | "让开别挡我的路"（7字）→ 约1.8秒 |

**时值计算规则：**
- 无台词镜头：纯动作/反应/空镜，按叙事需要估算（2-5s）
- 多句台词连续：累计字数后按语速换算，中间加0.3-0.5s停顿
- 情绪停顿：爆发前、情感释放后，额外加1-2s反应时间
- 同一场景内语速保持一致，语速变化应有明确情绪动机
