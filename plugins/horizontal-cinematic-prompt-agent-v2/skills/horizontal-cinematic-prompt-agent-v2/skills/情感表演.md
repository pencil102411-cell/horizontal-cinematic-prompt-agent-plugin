# 情感表演 Skill — 横屏真人影视

> 适用模型：Seedance 2.0 及同类视频生成模型
> 适用类型：横屏真人古装、仙侠、武侠中的对白、反应与情绪戏
> 核心目标：把人物目的、关系压力和情绪变化编译成镜头可见、尺度可控、能够衔接下一镜的表演。
>
> **写法约定**：最终提示词使用中文自然语言。`L1-L5`、`T0-T4` 等代码只供内部判断，不写进交付给视频模型的提示词。
>
> **镜头约束**：表演服从分镜与景别。中景及更近景别使用 85mm 以上，一个镜头只给一个精确焦距，并写清机距、透视和景深的可见结果；完整规则见 `references/镜头与灯光词典.md` §2.2。

---

## 0. 调用与优先级

出现可见人物、对白、反应、情绪转折或表演连续性问题时使用本文件。

执行优先级：

```text
用户本轮明确要求
> 当前项目的场次记忆
> 《风起玲珑骨》人物表演圣经中的角色、阶段与关系
> 当前剧情和镜头条件
> 本文件的通用表演语法
> 示例与词库
```

- 命中《风起玲珑骨》人物时，先读取 `references/风起玲珑骨/人物表演圣经.md`，再做当前场景适配。
- 人物圣经提供稳定底色，当前剧情决定这一刻怎么演；不得把示例动作机械复制给所有角色。
- 只保留镜头看得见、时长容得下的行为，不为显示“演技”堆满五官和肢体。

## 1. 表演的内部发动机

表演是人物在压力下采取的行为，不是情绪标签。落笔前在内部确定：

- **目标**：人物此刻想让具体对象做什么。
- **阻力**：什么使目标无法直接达成。
- **代价**：失败会失去什么。
- **策略**：人物现在采用劝、压、躲、试探、拖延、讨好、挑衅、隐瞒等哪一种可演行为。
- **转折触发**：哪句台词、哪个动作或哪个发现让策略改变。
- **潜台词**：人物想藏住什么，身体又泄露了什么。

这些项目只用于组织表演，最终提示词直接写行为。例如：

```text
帝鸿等帝江把话说完，目光先落到他手里的吊坠上，随后才抬眼看他；下颌收紧一次，把追问压成平稳低声，右手仍停在身侧没有伸出。
```

不要在提示词中输出“目标、阻力、策略、潜台词”等分析标签。

## 2. 最小表演弧与时长

优先使用以下五个节点：

```text
基线 → 触发 → 一处泄露 → 控制或行动选择 → 可持续终态
```

- **基线**：刺激出现前的面孔、视线、姿态和手上任务。
- **触发**：人物听见、看见、认出或触碰到什么。
- **泄露**：只让一个生理或动作信号先暴露情绪。
- **控制/选择**：人物压回情绪、改变策略或采取行动。
- **终态**：能稳定保持、能直接作为下一镜起点的表情和姿态。

短镜头可以合并相邻节点，但不能省略触发和终态。

| 可用时长 | 表演容量 |
|---|---|
| 3–5秒 | 一个策略或动作状态，加一个反应/结果；通常2–3个可见状态 |
| 6–10秒 | 最多两个清楚节拍；通常3–4个可见状态 |
| 10–15秒 | 两到三个有动机的节拍；通常3–5个可见状态 |

一个镜头最多一次主要情绪反转。表演强度没有变化时，不强行制造“高潮和回落”。上一镜的强情绪会留下惯性，下一镜不能无因重置为中性脸。

## 3. 表演尺度与泪态

### 3.1 内部强度等级

| 等级 | 可见幅度 | 使用原则 |
|---|---:|---|
| L1 泄露 | 5%–15% | 只改变一个通道；适合高位人物、公开场合和严密伪装 |
| L2 可读 | 15%–30% | 一个主动作加一个辅助信号；默认等级 |
| L3 临界 | 30%–50% | 只把泪线、唇颤、呼吸或身体中的一个通道推高 |
| L4 释放 | 50%–70% | 允许一次明显释放，通常只放在结尾1–2秒 |
| L5 失控 | 70%以上 | 哭喊、跪倒、剧烈挣扎；只有剧情明确要求且景别容纳时使用 |

角色地位高、处于公开场合、必须守礼或正在隐瞒时，默认下调一级。独处、最后防线断裂或明确爆发时才允许上调。最终提示词写具体动作，不写等级代码。

### 3.2 单一泪态

每个镜头只能选择一种终点泪态：

- **T0 干眼**：不红、不湿、不落泪。
- **T1 红或湿**：眼眶浅红或下睫毛湿润，不形成泪滴。
- **T2 悬泪不落**：泪珠停在眼缘，结尾仍不滑落。
- **T3 单滴泪**：转折后只有一滴从一侧滑落。
- **T4 决堤**：连续泪流，只用于明确的高强度崩溃。

先选泪态，再删除所有冲突词。进入单滴泪或连续泪流后，后文不能再写“始终无泪”；“不流泪”也不能和“泪珠滑落”同时出现。没有剧情依据时不主动加泪。

## 4. 可见通道与可靠性

优先级：

```text
视线落点 > 眼睑张力 > 嘴角方向 > 下颌/吞咽 > 呼吸 > 泪线 > 瞳孔尺寸
```

| 通道 | 稳定写法 | 注意事项 |
|---|---|---|
| 视线 | 失焦、聚焦、垂眸一次、看回、锁定、短暂避开 | 眼睛先找到目标，头部随后转动；不要多向乱扫 |
| 眼睑 | 上眼睑轻压、缓慢掀开、短暂闭合、下眼睑轻颤一次 | 轻压与圆睁不能同拍 |
| 嘴角/双唇 | 笑意停住、慢慢归平、闭唇浅笑、唇线压平 | 闭唇不能与台词或张嘴大笑同拍 |
| 下颌/喉头 | 下颌线收紧、喉头轻滚一次、把话咽回 | 一次足够，避免持续抽动 |
| 呼吸 | 屏息半拍、短吸气、缓慢呼气、一次轻叹 | 屏息与急促呼吸分成前后两拍 |
| 手与身体 | 指尖停住、握物力度改变、肩线下沉、重心转移 | 必须与现实动作、支撑点或道具发生关系 |
| 社交距离 | 守住距离、斜向靠近半步、伸手停住、接触后退开 | 距离变化需要剧情触发，一镜最多一次 |

不要单独依赖“瞳孔骤然放大”“眼底有光”“寒意渐浓”等不稳定或抽象表达。震惊可写成“目光骤停、眼裂略增、屏息半拍”；警觉可写成“目光凝实、上眼睑轻压”。

### 泄露点

复杂情绪默认让人物大部分表情维持公开面具，只通过一处小变化泄露真实情绪，例如喉头轻滚、指尖停住、下眼睑轻颤一次。每个状态只保留一个主变化，至多增加一个辅助泄露。

## 5. 景别适配

- **远景/全景**：优先轮廓、重心、步态、人物距离、进退路线和群体节奏，不写睫毛或嘴角细颤。
- **中景**：优先身体朝向、双手、道具任务、呼吸、人物距离、倾听和一次策略变化。
- **中近景/近景/特写**：优先念头先于台词、眼睑、视线焦点、下颌、吞咽、呼吸和面具裂缝；景别越紧，手势越少。
- **大特写**：只保留一个念头变化、一个视线目标、一次呼吸或肌肉动作和一个结果。

分镜已经指定景别时，通过调整表演细度适配，不擅自换镜头。没有分镜时才把景别作为建议。皮肤毛孔、绒毛、妆容精度属于材质或画质，不作为微表情的必写前置词。

## 6. 倾听、对白与多人反应

### 倾听

- 对手说话时，当前人物不能保持无原因的空白中性脸。
- 反应可以从对方一句话尚未说完时开始，但必须由明确字词、动作或物件触发。
- 困难回答前保留一次短判断：目光停住、呼吸改变或手上动作暂停，然后再说。
- 人物手里原本在做事时，可用“动作停半拍”给台词标点；不要每次都靠挑眉或转头。

### 眼神生命

- 宏观视线遵守人物站位和轴线，微观眼动服从思考与倾听。
- 受控静止要写出“压住动作、目光仍跟随对方”，不能像画面暂停。
- 眼睛可见时，眼神光必须来自实际光源，不凭空增加。

### 声音与口型

- 同一角色保持稳定的音色、语速和基础说话方式；场景只改变音量、气息、停顿和压力。
- 台词前后的呼吸、吞咽和停顿必须符合可用时长，口型严格对齐原台词。
- 受伤、醉酒、衰老或附体造成明显声音变化时，写成当前阶段状态，不改变角色身份。

### 多人镜头

- 明确主表演者，其他人只给低幅度、错开时间的反应。
- 群体反应不要同时发生，除非剧情明确要求整齐动作。
- 多人关系通过谁先看谁、谁停手、谁靠近、谁退让来呈现，不写“众人情绪复杂”。

## 7. 肢体落地与道具任务

公式：

```text
姿态/承重点 + 手上的现实任务 + 触发后的中断或变化 + 终点状态
```

- 明确身体由哪里承重，例如右肘压住桌面、左手撑地、双脚重新落稳。
- 给人物一个与剧情有关的手上任务，例如翻找、擦拭、整理、斟茶、收起、握住或递交。
- 用任务的停顿、加速、失手或恢复表达情绪，比无目的摆手更稳定。
- 战损、疲惫、湿身和受伤只写当场可见且会影响动作的状态，例如护住伤侧、换重心延迟、湿袍更重、呼吸变浅。
- 衣摆、袖口、发丝和佩饰必须晚于身体主动作产生余势，不得无因持续飘动。

古装场景不得直接复制现代职场、餐厅、领带或现代杯具范例。

## 8. 常用克制表演弧

### 克制怒意

```text
上眼睑轻压、目光锁定触发对象；下颌线收紧，喉头轻滚一次；慢慢呼出一口气，把声音压回平稳，终态保持冷静注视。
```

默认不用瞪眼、全身发抖、青筋暴起、咆哮或落泪。

### 震惊到确认

```text
目光骤停在证据上，眼裂略增，屏息半拍；手上动作停住；闭眼短促整理呼吸后重新看回，终态落在确认后的明确行动。
```

避免只写瞳孔变化，也不要自动接哭泣或释然。

### 害羞或心动

```text
听见触发后停半拍，短暂避开一次视线；闭唇浅笑只泄露一点，随后看回或轻点一次头，终态保持安静回应。
```

不用反复偷看、连续点头、咬唇、缩肩、大幅脸红和“眼神发亮”同时叠加。

### 隐忍悲伤

```text
原本的动作慢半拍，目光从对方移到手中物件；下眼睑轻收紧，喉头轻滚；继续完成手上的事，按已选泪态停在含住、悬住或单滴落下的唯一终态。
```

### 疲惫与释然

```text
眼睑略沉，呼吸由浅变深；肩线随一次长呼气缓慢下沉，手臂卸力落到明确支点；终态保持仍有重量的放松，不突然焕发精神。
```

### 慢燃关系戏

通过视线停留时间、人物距离和未完成触碰表现关系变化。一个镜头只改变一次心理距离：避开后看回、守距后靠近半步、伸手停住后收回，三者择一；不套固定15秒四段模板。

## 9. 硬互斥与过演防护

同一状态出现下列组合时必须删除一边：

1. 失焦与锁定同一点。
2. 上眼睑轻压与双眼圆睁。
3. 始终直视与垂眸、侧看或扫视。
4. 闭唇与说台词或张嘴大笑。
5. 无泪终态与泪珠滑落。
6. 身体纹丝不动与握拳、后退、转身等身体动作。
7. 大特写只演脸与跪倒、捶地、抱膝等画幅外动作。
8. 同一拍屏息与急促呼吸。
9. 冷笑不入眼与眉眼同步含笑。
10. 同一拍下巴内收与下巴上扬。
11. 嘴角归平与笑容继续扩大。
12. 无台词与持续可见口型。

过演防护：

- 每个状态只留一主一辅，一秒内最多两个可见变化。
- 短促触发后留一拍供观众读取，不连续堆瞳孔、眉、鼻翼、嘴唇、下巴和肩膀。
- 害羞、悲伤、愤怒和震惊都从 L1-L2 起步，剧情明确要求才上调。
- L4-L5 通常只占结尾1–2秒；整段都高强度时先检查是否缺少基线。
- 不让不同人物共享同一套微表情、停顿和手部习惯。

## 10. 常见失败修复与验收

| 问题 | 修复方法 |
|---|---|
| 只有“神情复杂” | 补明确触发、一个主通道、一个辅助泄露和终态 |
| 表情像静止面具 | 加视线或手上任务的前后变化，不堆更多形容词 |
| 表演太夸张 | 下调强度，只保留一主一辅，删除无剧情依据的泪和大动作 |
| 表演太满 | 按时长减少节拍，优先保留触发和终态 |
| 多人同框抢戏 | 指定主表演者，其他人错开并降低反应幅度 |
| 接不上下一镜 | 写清结束时的目光、手位、姿态、距离和呼吸，并同步到本场连续性状态 |
| 台词像背词 | 加倾听反应、回答前判断和说话时的稳定行为 |

交付前检查：

- [ ] 当前人物的行为是否由明确目标、阻力或刺激驱动？
- [ ] 每个状态是否只有一个主变化和至多一个辅助泄露？
- [ ] 表演尺度是否符合人物、关系、场合、景别和时长？
- [ ] 泪态是否唯一，是否存在“无泪”和“泪落”冲突？
- [ ] 对手说话时是否有真实倾听，而非空白脸？
- [ ] 远景是否误写看不见的微表情，大特写是否写了画幅外动作？
- [ ] 是否明确了能够承接下一镜的终态？
- [ ] 最终提示词是否删除了 L/T 等内部代码和分析标签？
