# 动作戏 Skill — 横屏真人古装影视

> 适用模型：Seedance 2.0 及同类视频生成模型
> 适用类型：横屏真人古装 / 仙侠 / 武侠动作戏
> 核心目标：消除塑料感、平移感、PPT瞬移、凭空飞行、随机镜头，输出工业级动作分镜提示词
>
> **写法约定**：本文件所有提示词条目均为**中文主干 +「中文（English keyword）」**格式，可直接誊入【时间轴】。运镜、材质、VFX、布光四类专业术语附英文，其余一律纯中文，不写整句英文。

## 0. 总控原则

### 0.1 三大核心美学

**空间借力与威亚质感 (Wire-fu)**
角色在三维空间的移动必须包含"踏点"与"借力"，不能凭空飞行。
✅ 轻点水面 / 踩踏碎裂桌板 / 沿柱奔跑 / 精准踩肩借力 / 脚踏空气涟漪 / 踩在香炉边缘借势

**介质破坏与物理反馈 (Environmental Destruction)**
用环境破坏具象化"内力"与"打击感"。
✅ 剑气激起水幕 / 爆裂木屑 / 气流卷起枯叶 / 斩断飞檐瓦片 / 地面炸裂烟尘 / 柱子崩裂

**变速剪辑 (Speed Ramping)**
拒绝全程匀速。
- 兵刃相交 / 水花炸裂瞬间 → 极慢动作升格
- 人物突进 / 拔刀瞬间 → 高速残影
形成极致视觉反差。

### 0.2 四个硬约束

1. 必须时间轴分段（15秒请求可参考 0-3 / 3-8 / 8-12 / 12-15，**实际切分以用户选择的总时长和动作节拍为准**，不为凑四段而拆——下方各模式的三段、四段切法都是合法的）
2. 每段必须写：景别 + 单一精确焦距/景深结果 + 运镜 + 动作 + 环境反馈 + 节奏；焦距规则见 `references/镜头与灯光词典.md` §2.2
3. 必须有动作链因果：触发 → 传导 → 结果
4. 必须有物理反馈：受击反应 / 重心变化 / 冲击波 / 碎屑 / 遮挡

室外动作中的风、雨、雪、雾和扬尘要进入同一受力链：环境方向与人物衣发、兵器轨迹、植被/积水及光线反馈一致，细则见 `references/室外环境动力.md`。

### 0.3 徐克武侠风格关键词包

用于古装武侠场景的整体视觉基调叠加，不作为独立段落而是融入模板：

**核心视觉符号：**
- 超高速转体特写 / 兵器高速碰撞火花 / 兵器脱手旋转慢镜
- 广角变形 + 超纵深构图 / 慢动作布料延展 / 多角度碎片爆破
- 飘逸纱幔与金属冷光对撞 / 高速划过的竹叶/雪花/花瓣
- 逆光剪影打斗 / 烟尘中若隐若现的刀光

**提示词写法：**
> 徐克式武侠美学，威亚动作编排（wire-fu），广角变形镜头（wide-angle distortion）拉出超常纵深，布料在慢动作中层层延展，碎屑高速迸散，逆光剪影下的搏杀，兵刃相交迸出火星

**使用方式**：在任意动作模板的"画面定调"模块中择 2-3 个视觉符号注入，不做全量堆叠。

### 0.4 画面清晰法则

- 固定指令：运动模糊只作用于背景（motion blur on background only）
- 强制：角色和武器边缘清晰锐利
- 高速段至少加入一个：变速过渡（speed ramp）／动态运动模糊（dynamic motion blur）／能量拖尾（energy trails）

### 0.5 动作注意力控制法

- **绝对主体唯一化**：每段只能有一个视觉锚点（主攻者/受击者/追逐目标），不能在同段内反复切换
- **核心动作单线程**：每段只保留一个主要动作目的（起势/首击/变招/收束），避免塞入多个复杂动作
- **辅助动作从属**：武器轨迹、脚步、衣摆、碎屑、受击反馈必须服务核心动作，不得独立抢戏
- **客体边界约束**：对手、群演、环境破坏只是承托主动作的客体，描述时限制其动作幅度
- **镜头锚点锁定**：背跟/FPV/受击跟随/侧向平跟只能选一个主锚点，避免高速段随机漂移
- **时间节奏分段**：0-3起势 / 3-8爆发 / 8-12变招 / 12-15收束，每段只解决一个主要变化

### 0.6 人物动作动力链与连续性锚点

动作戏中的人物表演不能只靠“有力量感”“动作凌厉”等形容词。每个主要动作按以下因果链组织，短动作可合并相邻节点，但不能省略起点、接触因果和终点：

```text
起始锚点 → 准备动作 → 动力链 → 主动作/接触 → 受力响应 → 余势 → 回收/终点锚点
```

- **起始锚点**：人物左右位置、朝向、支撑脚、持物手、双方距离和起始目光。
- **准备动作**：目光先锁目标，吸气或屏息，重心转移到明确支撑脚，参与发力的关节预载。
- **动力链**：力量按脚掌、膝、髋、腰、肩、肘、腕、手的实际参与顺序传导；小动作只写真正参与的部位。
- **主动作/接触**：一段只保留一个主要攻防事件；双人动作写清主动者、唯一接触点、力的方向和受力者。
- **受力响应**：受力者的头、肩、躯干、脚步或道具沿同一力向响应，不能无接触自行飞退。
- **余势**：发丝、衣摆、袖口、佩饰、雨雪、液体和碎屑在主动作之后延迟半拍运动。
- **终点锚点**：写清手脚回到哪里、重心如何落稳、双方最终距离、目光和呼吸；下一镜从同一状态开始。

人物性格通过动作参数表现：速度、幅度、重心习惯、视线先后、呼吸、手部习惯、社交距离和回收方式。克制者预备较慢、幅度较小、回收干净；暴烈者预备短、幅度大、动作硬停；受伤者保护伤侧、换重心延迟；温柔者斜向靠近、接触轻、指尖最后离开。性格只能改变动作质地，不能破坏关节顺序、接触点、受力方向和连续性。

连续镜头至少核对：人物左右位置、朝向、支撑脚、左右手分工、持物手、接触侧、动作终点、衣发余势方向。不得只写“延续上一条动作”；必须把这些可见状态重新写入下一条提示词。

## 1. 物理反馈系统

### 1.1 节奏法则（Fast-Slow-Fast）

| 阶段 | 说明 |
|------|------|
| 慢（蓄力） | 长时间大拉扯的蓄力前摇，建立张力 |
| 极快（出击） | 出拳/出刀瞬间极快，带有残影 |
| 微停顿（Hit Stop） | 命中瞬间画面几乎停住，汗珠、碎屑、发梢悬在半空后才继续下落。力量感来源 |
| 余韵 | 终结后环境与粒子收束 |

### 1.2 受击反馈法则

不要只写"A打B"，必须详细描写受击方状态：
- 命中瞬间重心失衡后倒
- 受击侧脸颊肌肉被冲力向后带开，嘴角被打散，头颈随力偏转，汗珠与唾沫脱离面部
- 向后抛飞 / 砸入地面
- 身体出现真实受击反作用力

> **禁止写「面部扭曲」「面部形变」这类词。** 面部崩坏是 AI 视频最高频的失败模式，而【固定约束】里正写着「不扭曲」——正文再出现这四个字，等于给模型发许可证，两条指令打架，选错整条报废。要表达受击感，就按上面第二条写具体的肌肉与力的方向。

### 1.3 环境联动法则

让环境跟着受力联动，烘托打击重量感：
- 脚底尘土飞扬
- 空气炸开冲击波 (Shockwave)
- 碎石四处飞溅
- 瓦片断裂 / 地面砸出坑 / 柱子崩裂 / 铁香炉爆发火花

## 2. 镜头调度字典

### 2.1 景别选择

| 景别 | 适用场景 |
|------|---------|
| 广角全景 (Wide Shot) | 环境全貌、长距离轻功追逐、群攻包围 |
| 中景跟随 (Medium Tracking) | 连招交互、双人配合、半身动作展示 |
| 低角度仰拍 (Low-angle) | 强化跳跃高度、飞檐走壁压迫感、英雄登场 |
| 环绕运镜 (Orbit Shot) | 被包围时全方位防守、背靠背协同展示 |
| 微距特写 (Macro Close-up) | 眼神、兵器反光、水滴滑落、情绪张力 |
| 越肩跟拍 | 敏捷角色追逐、动量连续感 |
| 受击跟随 | 力量型角色、被击飞瞬间锁定受击方 |

### 2.2 机位角度

- **略低角度**：强化强势者压迫感，适合主角突进、攻击者
- **略高角度**：表现弱势、被压制、受击后退
- **侧面镜头**：动作方向清楚，适合横向突进、格挡、击飞
- **过肩镜头**：对峙压力、视线关系、双人攻防

### 2.3 角色相对位置姿态

提示词中必须明确空间关系：

**上下关系：**
- 一楼台阶下与二楼屋顶的立体攻防
- 半空与地面的呼应配合
- 屋顶高处与地面低处的夹击

**前后/接触关系：**
- 背靠背防御
- 精准踩在肩膀上借力腾空
- 从背后突袭到正面格挡的转换

## 3. 五类动作模式

> A 高动态近战 / B 瞬移高速连招 / C 仙侠追逐 / D 轻功与飞行 / **E 御剑飞行互动镜头**
> E 在最下方，是本节最实用的一段，别读到 D 就停。

### 模式A：高动态近战 (Melee Impact)

**目标**：把软动作升级为"可感知重量"的动作戏

**必注入元素：**
- 受击反馈：失衡、后仰、抛飞
- Hit Stop（命中停顿）
- 环境联动：地裂、碎石、冲击波、木屑飞溅
- 运镜策略：敏捷角色用越肩跟拍，力量角色用锁受击者跟拍

**15秒分段：**
- [0-3s] 蓄力压迫（中近景，低机位推镜）
- [3-8s] 首轮爆发（贴身跟拍，1个Hit Stop）
- [8-12s] 变招压制（侧移/环绕 + 环境破坏）
- [12-15s] 终结收束（俯拍拉远 + 烟尘余波）

### 模式B：瞬移高速连招 (Teleport Combo)

**目标**：解决"瞬移=跳帧"，建立连续可视运动轨迹

**核心修正：**
- ❌ 禁止写：A瞬移到B面前攻击
- ✅ 必须写：A点 → 轨迹显现（残影/烟雾/雷电/流光）→ B点落位 → 命中定格

**必注入术语：**
- 能量拖尾（energy trails）
- 动态运动模糊（dynamic motion blur）
- 轨迹连续无断点，落点之间有可见的路径残留
- 路径形态：Z字折线／S形曲线／折叠路径

**三段节奏：**
- [0-5s] 子弹时间蓄力，镜头推入侧脸/脚步，敌方动作趋近停滞
- [5-10s] 多落点闪现连击，每个落点有清晰定格
- [10-15s] 主角收招，群体受击结果同时爆发

### 模式C：仙侠追逐 (Fantasy Chase)

**目标**：追逐具备沉浸感、速度感、空间逻辑

**镜头锚定：**
- FPV视角：复杂穿梭、空战、峡谷/建筑穿行
- 背部锁定（1-2米）：轻功跑酷、近地追逐
- 撞击点：手持震动 (handheld shake)

**动作链法则（示例）：**
击中支撑架 → 飞檐失衡坠落 → 阻断追兵路径

**15秒分段：**
- [0-4s] 被追击起跑（背跟/FPV，腾空起势）
- [4-10s] 高速规避（变速过渡 + 复杂地形/建筑穿梭）
- [10-15s] 环境反杀或脱离（俯拍拉远收束）

**一镜到底追逐进阶（多段衔接）：**

用于连续穿越多个空间的长距离追逐。核心技巧：

```
单镜头内：地形变化 → 速度变化 → 方向变化 → 景别自然过渡

段落衔接公式：
[段落A终点即段落B起点] + [速度渐变] + [地形/障碍切换] + [镜头锚点不变]
```

**写法示例（竹林→悬崖→水面三段衔接）：**
> 追逐始于密竹林，第一人称视角（FPV）在角色身后跟随，角色在竹竿之间腾跃借力。竹林渐疏，地形过渡到崖边——角色不作停顿直接跃出悬崖，镜头随之下俯跟坠，变速过渡（speed ramp）进入慢动作。角色撞入水面，镜头穿过溅起的水花转为水下跟拍，气泡与碎屑在身后拖成一条尾迹。

**关键约束：**
- 每段衔接处必须有"过渡介质"（飘过的竹叶/翻飞的衣摆/溅起的水花），不能硬切
- 速度必须在过渡介质处渐变（不可突变），变速点写成变速过渡（speed ramp transition）
- 镜头锚点全程不变（FPV 即全程 FPV，背跟即全程背跟）

### 模式D：轻功与飞行 (Wire-fu & Flight)

**目标**：消除"吊威亚感""直线平移感"

**轨迹定制：**
- 力量型：Z字折线 / 二段弹射
- 飘逸型：螺旋上升 / S形曲线

**三大物理反馈：**
1. 起跳反作用力：地裂/水花/烟尘下压，瓦片崩碎
2. 空气阻力：发丝后拉、衣摆延展、披风贴体
3. 空中借力点：脚踏空气涟漪 / 虚空莲花 / 踩踏实体（水面/柱顶/香炉边缘）

**15秒分段：**
- [0-3s] 蓄力起飞（低仰拍，地面破坏）
- [3-8s] 轨迹腾空（螺旋或Z形，服饰延展）
- [8-12s] 空中变向（借力点触发）
- [12-15s] 远遁/终击（拉远留白）

### 模式E：御剑飞行互动镜头 (Sword-Riding Flight Interaction)

**目标**：解决御剑飞行"人在空中平移""只是站着飘""飞剑被拿在手里"的问题，让飞行具备真实速度、空间反馈和镜头沉浸感。

**核心判断：**

御剑飞行不能只写"人物御剑飞行、速度很快、衣袂飘动"。真实感来自五层互动：

```
人物互动 + 飞剑互动 + 环境互动 + 镜头互动 + 光影互动
```

如果缺少近景参照物、环境反馈和镜头参与，画面会变成无聊的空中平移。

**人物互动：**

- 身体微微前倾，重心随飞剑转向轻微调整
- 衣袖、披帛、发丝被风压向后拉动
- 中近景可加入"短暂看向镜头，再看回前方"的眼神互动
- 避免双臂张开、挥手、舞蹈动作、僵直站立

示例：
> 女主双脚前后错位稳立飞剑中段，身体微微前倾，双手背在身后，披帛被强风向后拉直；她短暂转眼看向镜头，与观众有一瞬间对视，然后重新看向前方。

**飞剑互动：**

- 飞剑必须影响空间，不能只是脚下光条
- 切开云雾、压出水池波纹、擦过石柱或山壁带起薄雾
- 转向时飞剑微微侧倾，剑尾留下细长流光轨迹

示例：
> 脚下飞剑贴着石台栏边高速掠过，气流擦过石柱基座卷起一圈白色薄雾，水池被风压压出弧形波纹。

**环境互动：**

速度感来自近景参照物，不来自"很快"两个字。每段高速飞行至少加入 2 类近景互动：

- 石柱从镜头两侧高速掠过
- 山壁近距离擦过
- 云雾从镜头两侧被劈开
- 水面被风压推开
- 桥柱、台阶、岩壁形成纵深视差

示例：
> 近处石柱、山岩和云层从镜头两侧急速掠过，形成强烈纵深视差。

**镜头互动：**

- 镜头不能只是旁观，必须参与飞行
- 正前侧方中近景贴身跟拍，或从前侧方沿平滑弧线滑到背后侧方
- 披帛、云雾、石柱可短暂扫过镜头前景形成遮挡
- 背景运动模糊只作用于环境，人物和飞剑保持清晰

示例：
> 摄像机从人物正前侧方沿平滑弧线滑到背后侧方1-2米贴身跟拍，披帛从镜头前景快速扫过形成短暂柔软遮挡。

**光影互动：**

- 水池冷蓝反光闪过脸侧
- 云影或山壁阴影短暂压暗人物
- 穿出云层后逆光勾亮白衣轮廓
- 飞剑灵光照亮鞋底、衣摆下缘、近处薄雾

示例：
> 山壁阴影短暂压暗人物，随即进入云缝天光，白衣轮廓被逆光勾亮，飞剑灵光照亮衣摆下缘。

**御剑姿势稳定约束：飞剑的双重身份**

**飞剑既是武器也是飞行载具，同一柄剑在不同段落承担不同身份。** 模型的失败点不是"剑不该在手里"，而是**同一段里兼任两者**——脚下踩着剑、手里又握着一柄，或者身份无过渡地跳变。规则是按段落锁定身份，切换必须写出交接动作。

| 段落性质 | 剑的身份 | 必写 |
|---------|---------|------|
| 飞行段（穿行、掠水、破云） | 脚下载具 | 剑横向悬浮于双脚正下方承载体重，双脚清楚踩在剑身中段，**手中无物** |
| 近战段（落地接战、格挡、劈刺） | 手中武器 | 剑在掌中，握位与劈刺方向清楚，**双脚落地或另有借力点**，不再踩在剑上 |
| **离体飞击段（御剑攻击、飞剑取敌）** | **离体法器** | 剑**既不在脚下也不在手中**，脱手远程飞击；人站定或另有踏点，手结驭剑指诀、视线锁住剑的去向，剑的飞行轨迹全程可见 |
| 交接段（起飞、落地、放剑、收剑） | 过渡中 | 必须写出交接动作本身，见下 |

> **御剑攻击属于离体飞击，不是手持劈刺。** 这是最易写错的一格——把"御剑攻击"当成握剑挥砍，动作性质就整个反了。判断只看一件事：**这一段剑离不离手。**

飞行段写法：
> 脚下是一柄横向悬浮的细长银白飞剑，始终位于女主双脚正下方，承载其全部体重。女主双脚清楚踩在剑身中段，手中没有任何物品。

近战段写法：
> 女主自剑上跃起落于石阶，飞剑同时脱离脚下、旋身入掌，她反手握住剑柄，剑尖斜指地面。

离体飞击段写法：
> 女主立于石阶不动，右手二指并拢竖于胸前作驭剑指诀，目光锁住前方；飞剑离她三丈之外自行转向，剑身贴着水面高速掠出一道笔直白痕，直取敌阵。

**交接动作词库（不可省略，省了就是瞬移）：**

| 身份切换 | 交接动作 |
|---------|---------|
| 武器 → 载具（起飞） | 剑自掌中脱手 → 横向悬停于脚前 → 人踏上剑身 → 剑携人升起 |
| 载具 → 武器（落地接战） | 人自剑上跃下 → 剑同步脱离脚下 → 旋身入掌，反手握住剑柄 |
| 载具 → 离体（空中放剑） | 足尖点剑身借力弹起、落于实处 → 剑自其下方抽离 → 悬停身侧待命，剑尖已指向目标 |
| 武器 → 离体（放剑） | 掌心一送，剑脱手前冲 → 人手指并作指诀，视线锁住剑的去向 |
| 离体 → 武器（收剑） | 飞剑回旋掠回 → 人抬手截住剑柄 → 顺势下压，剑尖斜指地面 |

**15秒分段：**

- [0-3s] 环境起势：建立起飞点，水面/云雾/石柱保持可互动
- [3-6s] 入画与人物互动：脚下飞剑的承载关系清晰，中近景可短暂看镜头
- [6-11s] 高速穿行：贴近石柱、山壁、云层、水面，制造环境反馈和纵深视差
- [11-15s] 远遁收束：速度回落，云雾合拢，保留飞行轨迹余韵

**快速检查清单：**

- 是否有人物看镜头或重心调整？
- 飞行段是否明确双脚踩在飞剑上、手中无物？身份切换处是否写了交接动作？
- 是否有飞剑对水、雾、石柱、山壁的反馈？
- 是否有近景参照物高速掠过？
- 是否有披帛、云雾、石柱造成前景遮挡？
- 是否有明暗变化，而不是全程平均光？
- 飞行段是否避免了张开双臂、僵直站立、空中平移？（**剑该不该在手里，按当前段落的身份表判定，不是一律禁止**）

## 5. 场景模板库

### 模板A：竹林轻功追逐与反杀（空间纵深）

```
电影级广角跟随镜头。翠绿的竹林中，阳光透过竹叶洒下斑驳光影。
身穿[角色服装]的[角色A]手持[武器]在竹林间高空飞跃，双脚踩在弯曲的竹干上借力闪躲。
随后镜头瞬移推进，[角色A]在半空中猛烈转身，与多名刺客激烈碰撞，火花四溅。
动作节奏加快，[角色A]在空中完成流畅连招并顺势飞踢。
画面在戏剧性慢动作中，[角色A]单膝落地缓冲，激起满地落叶飞舞，长剑斜指泥地定格，眼神冷酷。
```

### 模板B：水战变速与物理特效（物理反馈）

```
电影级动作长镜头。极端青蓝色调，浓雾弥漫的平静水面。
广角镜头：身穿[角色服装]的[角色A]独自立于竹筏上。
刺客突袭，画面进入中景升格慢动作：[角色A]瞬间拔剑，剑刃平贴划破水面，
激起数米高的巨大半透明水墙拦截暗器。
特写转全景：水幕下落瞬间，镜头急速推进变速，[角色A]化作残影向前突进，一击斩过敌阵。
画面定格：[角色A]背对敌人，长剑斜指水面，水滴缓缓滴落，高对比度剪影。
```

### 模板C：古建多层双人立体协同（机位调度）

```
15秒持续动感长镜头。幽暗青蓝色调，深夜浓雾锁闭的荒废古寺大殿前。
全景开场：[角色A]与[角色B]背靠背被围困在台阶下。
镜头快速环绕：[角色A]长剑轰击巨大生锈铁香炉，爆发出火花（升格慢动作）。
[角色B]借势腾空，踩在香炉边缘掠向大殿屋顶。
低角度仰拍：[角色B]在屋顶高速奔跑，斩断飞檐瓦片砸向地面；
[角色A]在台阶下配合坠落的瓦片极速突进。
画面在两人一上一下立体配合绞杀的极速动态中结束，动作不收尾。
```

### 模板D：匹配剪辑双环境动作（心理空间切换）

适用场景：角色在安全/回忆场景与危险/现实战斗场景之间切换，用匹配动作做心理空间的跨越。

**核心技巧：** 同一动作横跨两个完全不同的场景，以动作连续性缝合两空间。

```
15秒双场景匹配剪辑：

[0-2s] 场景A（安全/回忆）：
角色A在[安静室内/回忆场景]缓慢做出一个标志性动作——
抬手/转身/闭眼。柔光，暖色调，慢速推入。

[2-3s] 匹配剪辑过渡：
同一动作的起始姿态在场景B中无缝接续。色调从暖渐变至冷/青蓝。
利用衣袖/发丝/披风的运动方向一致做视觉桥接。

[3-10s] 场景B（战斗/现实）：
动作爆发——同一抬手变为拔剑格挡，同一转身变为闪避突刺，
同一闭眼变为睁眼迎敌。节奏加速，环境破坏，冷硬光。

[10-15s] 两空间叠影收束：
打斗余波中，场景A的暖色视觉残像短暂叠化出现，
角色眼神闪过一丝恍惚，随即被现实战斗拉回。
```

**古装适配：**
- 场景A → 场景B 映射示例：禅房抚琴 → 竹林搏命；烛前缝衣 → 城头迎敌；花间漫步 → 雨中拼杀
- 匹配动作选"慢→快"有天然张力的动作：抬手/拂袖/转身/迈步/抬头
- 色彩过渡：暖金→冷青蓝、暖琥珀→冷灰绿

> 本模板与特效戏 `skills/特效戏.md` §4.3 精神污染/叠影手法互补——匹配剪辑侧重"动作连续性"，精神污染侧重"心理破坏性"。

## 6. 常见失败修复

| 问题 | 修复方法 |
|------|---------|
| 画面软、无力感 | 加Hit Stop + 受击方抛飞 + 冲击波 |
| 速度感不足 | 背景运动模糊 + 环境破坏 + 变速过渡（speed ramp） |
| 瞬移像跳帧 | 补轨迹可视化（残影/烟雾/流光）+ 每落点动作定格 |
| 飞行像平移 | 补起跳反作用力 + 风阻服饰延展 + 空中借力点 |
| 御剑飞行无聊 | 加人物看镜头/重心微调 + 飞剑压水雾/擦石柱 + 近景参照物高速掠过 + 镜头前景遮挡 |
| 飞行段飞剑跑到手里 | 按段落锁定飞剑身份（载具/武器/离体三选一）：飞行段只写脚下承载 + 手中无物，近战段才写握持，御剑攻击写离体飞击；身份切换处补交接动作 |
| 凭空飞行无真实感 | 加踏点（水面/柱顶/虚空涟漪）+ 起飞地面破裂 |
| 镜头乱飘 | 锁单一锚点（背跟/FPV/受击跟随） |
| 动作抢戏 | 删除次要动作，只保留当前时间段核心目的 |
| 主体融合变形 | 明确主攻者/受击者视觉权重，弱化群演与环境物件 |
| 焦点漂移 | 固定镜头跟随对象，减少无意义环绕和推拉 |
