# 标准输出模板

> 用于最终完整视频提示词；检查、讨论、局部替换、场次记忆和插件维护按用户要求交付，不强套本模板。执行优先级与信息缺口处理以 `AGENTS.md` 为准。
>
> 完整提示词的五区块顺序为：素材引用 → 生成目标 → 光影设计 → 时间轴 → 保持一致。代码块内是生成指令；假设、拆点与必要说明放在代码块外。

## 输出骨架

以下是待填写的结构，不是可原样投喂的成品。按当前场景填写，删除不适用的占位内容；时间段数量由实际镜头和节拍决定。

````
【素材引用】
（只在使用关键帧时加这一行，并放在最前：以@图片X至@图片Y的顺序作为关键帧）
人物（按首次出场顺序；上传顺序与编号一致）：
@图片1、@图片2 共同定义[角色姓名]（正面、侧面），成片中只有一个[角色姓名]；只取面部、发型和本场服装，不取图片背景
@音频1 是[角色姓名]的音色；只取音色，不取原音频台词
@图片3 是[第二角色姓名]；只取面部、发型和本场服装，不取图片背景
其他主体：
@图片4 是[第二角色的法相或其他主体]；只取形态与颜色
场景：
@图片5 是[场景名称及方向]；只取空间结构和陈设，不取图中人物和光线
道具：
@图片6 是[道具名称]，归[角色姓名]所有；只取形制、材质和尺寸
动作/运镜参考：
@视频1 只参考[环绕运镜]路径和节奏，不取人物外观、场景和光线
声音参考：
@音频2 只参考[夜风环境声]，不取音乐

【生成目标】
横屏真人电影写实，古装仙侠。[主体]在[地点][事件]。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音；只保留台词、动作声和环境声。

【光影设计】
- 主光方位：[实际或拟定的光源方向]
- 光质：[硬光（hard light）/柔光（soft light）中的适用方案]
- 光比：[主体与背景、受光与背光的明暗关系]
- 动机光源：[已确认或本轮设计的灯具/窗外日月光/术法自发光等]
- 色调：[与当前时段、材质及情绪一致的色调]
- 主体与背景分离：[轮廓光/明暗反差/色彩差或自然融入背景的关系]

【时间轴】
0-8s：[景别]，[焦距及机距、透视、景深结果]，[机位/运镜]。[事件与表演]。[相关对象的互动与环境反馈]。[光影保持或变化]。[角色姓名]台词（语气）：{台词原文}。结束时：[位置、朝向、视线、持物]。
8-17s：[同镜连续或切镜]……结束时：……
17-30s：……结束时：[最终画面]。

【保持一致】
人物身份、人数、服装、道具归属、空间方向、光源方向保持一致。
人物为正常人眼，不发光。
不要字幕。不要音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音。
````

只引用本条实际出现或用于参考的资产；无第二角色、无关键道具时不保留对应行。无实际资产而使用占位时，在代码块外标注“需替换为实际资产名”。不要用未被提供的 @图片编号冒充已确认素材。

其他输出备注仅在需要时出现：工作时长或布光假设、拆条原因与切点、对原方案的具体差异、确有影响的待确认项。常规默认保护语的适配无需逐条解释；会改变用户预期的约束调整要说明。

## 生成目标与保持一致：保留适用内容，消除相反指令

风格和声音禁项写进【生成目标】，不超过 3 句；身份与连续性要求写进【保持一致】，不超过 5 行。声音禁项在【生成目标】和【保持一致】各写一次，每次列全同义词（音乐、背景音乐、BGM、配乐、器乐、旋律、氛围铺底音）。【保持一致】默认写“人物为正常人眼，不发光”；剧情设计了眼睛发光时，删除这一行。检查每个分句是否与当前已确认设计相容；冲突时作最小删改，保留仍有用的身份与连续性要求。不把相反指令同时交给视频模型。用户明确要求 BGM、字幕、变身、空间异变等时，对应默认内容让位，不让技巧示例覆盖用户禁项。

| 场面 | 用它调整【保持一致】 |
|---|---|
| 空间折叠、崩解、闪电或明暗骤变 | 锁定未变化的参照物，写清有意变化的区域和时段；不写全场环境或曝光永远不变 |
| 变身、兽化、人体解构、羽化消散 | 写起止身份和允许变化/遮挡的部位；不同时要求这些部位全程清晰、形态固定 |
| 时间冻结、命中停顿、瞬移连招 | 写明停顿或位移的对象、触发、路径/落点和结果；不追加“无卡顿无瞬移” |
| 环绕、越轴、追逐及主观切换 | 用可见过轴过程、空间参照或重新建立关系保证可理解，不强锁所有镜头的画面左右 |
| 手持、变速或固定观察 | 按当前运镜写稳定程度，不统一追加“平滑无抖动”或强制镜头运动 |
| 无人空镜、道具或手部插入 | 保留该镜涉及的材质、动作与空间连续性；不补不存在的人脸、口型或人物表演 |

人数、站位、持物、变化区域与动作结果优先在时间轴中正面写清。用户明确且影响结果的禁项可用一句简短约束，避免追加无关的否定词库。

## 素材引用：身份明确，事实与工作假设分开

先使用已提供的资料和当前场次有效资产，不把“向用户问过一次”作为输出条件。需要澄清哪些缺口按 `AGENTS.md` 判断；用户明确先出或缺口非关键时可用占位继续。

- 排序固定：关键帧顺序说明（只在使用关键帧时写）→ 人物组（含人物音色，按首次出场顺序）→ 其他主体 → 场景 → 道具 → 动作/运镜参考 → 声音参考。上传顺序和编号与人物首次出场顺序一致。
- 每一行写清是谁、控制什么、只取什么、不取什么；同一人物的多张图写在同一组，并加一句“成片中只有一个 X”。
- 只使用平台的真实代号（例如 @图片1，或平台里的资产名），不要发明 @人物1 这类代号。
- 每个资产一行，说明文字自带人物姓名、具体场景或道具身份。把 @ 名称遮住后仍能辨认对象。
- 已有资产图时，不重复五官、发型、服装形制和空间布局；当前表演与关系调度写入时间轴。
- 占位不代表已有实际文件；不为凑三类编造角色或道具。用户要求纯文生时按输入展开必要外观，拟定细节不当作已见资料。
- 图像决定可确认的结构与外观；本轮要求决定日夜、天气、开关灯、伤势、换装和破坏等变化。关键结构冲突说明差异，不让参考图的初始状态自动覆盖本轮目标。

## 光影设计：自洽的状态，不强制造变化

在主光方位、光质、明暗关系、动机光源、色调、主体与背景关系六个方面说明实际方案。可以合并相关项；按有依据的内容写，不为填满字段编造画外物件。自然融入背景或纯黑阶段也是可设计的关系，不强加轮廓光。

有场景图时读取灯具、窗门开口、材质固有色和空间层次；看不到的窗位和光源不当成事实。日月光、画外灯源及术法光可作为有依据的动机，不要求每个发光物都出现在画面中。只有资产名时可提出简洁自洽的工作布光，外部说明假设。

光线稳定就描述稳定状态；当角色遮挡光源、走入阴影、灯熄灭或术法自发光时，再写变化及照到的表面。连续条保持已确认光源关系；用户要求新的状态时表现过渡或明确切换。

## 时间轴：按镜头可见内容组织

每个镜头写清**景别与焦距/景深结果、机位与固定/运镜、主体事件及终态**；环境反馈、光影变化和声音按本段实际需要补充。固定镜头、稳定表演与稳定光线都成立。

### 焦距与运镜

- 普通镜头选一个精确全画幅等效焦距，不列范围或备选。明确镜内变焦时写起止焦距、连续变化及画面结果，不把它当两种备选。
- 默认大空间建立可用 24mm、28mm、32mm 或 35mm 中一个；全身关系可用 65mm；中景及更近优先 85mm、100mm 或 135mm 中一个。这些是审美默认，用户指定或具体叙事需求可选其他焦距。
- 将焦距落实为摄影机与主体的距离、前后景比例、空间透视与合焦范围；不要把任何焦距机械绑定固定机距或固定景深。
- 区分摄影机前后移动与镜头变焦；需要两者组合时写清组合结果。焦距为创作意图，机身、光圈、帧率等界面/后期参数不作为提示词精确控制承诺。

### 事件与衔接

- 一条视频、镜头、时间段和动作节拍采用 `AGENTS.md` 定义。一个镜头可含多个相互承接的动作；同一段有主导目的与因果链，不机械限制为一次出手。
- 互动角色可以有效进攻、还击、配合或接过叙事重点；明确作用和先后，不把“主次清楚”写成配角一律静止或弱化。
- 时间点连续，末段写实际秒数，不留 Ends 等占位。时间分段不等于切镜，镜内节拍写“同镜连续”，切镜则写清新的视点关系。
- 风雨雪雾、尘和日照变化出现时，写本体及画面内相关对象的反应。画面容得下时优先联系两类对象，特写或空镜不为凑数改变构图；持续天气可延续，不必每镜重新触发并回落。
- 写出能承接下一镜的可见终态：位置、朝向、动作阶段、视线、持物与相关环境积累状态；不只写“保持上一条”。

### 可见人物的表演

- 有人物且行为对叙事有用时，先写目的下的可见动作、触发和终态；不以“神情复杂”“眼神一冷”代替具体行为。
- 脸部清晰可读时写适量微表情；远景写重心、步态与距离；手部、道具、伤口插入和空镜写对应的物体变化，不强加脸部反应。
- 默认一个主变化和必要辅助泄露，按时长与节拍适配；不堆满五官，不为满足结构制造反转。
- 泪态明确且同一时刻不冲突；没有剧情依据不加泪。闭唇、说话、垂眸、直视等有先后变化时注明节拍，不同时堆写。

完整的动机、尺度、倾听和互斥规则见 `skills/情感表演.md`；技巧片段需要适配当前角色、镜头和时间，不直接机械复制。

### 台词与时长

- 对白统一写成 `角色台词（语气）：{台词原文}`；台词后面不追加语气、表情或动作描写（会诱发字幕）。画外音、旁白按实际声音来源写，不强加可见说话脸部。可见说话口型要求与台词对齐。
- 语速参考慢速每秒 2 字、中速 3 字、快速 4 字，标点不计，另加停顿和反应；只在需要时写气声、急促或拖长等声音表演。默认不加 BGM 和字幕，用户明确要求时按【生成目标】/【保持一致】适配。
- 时长按用户指定值，其次分镜时长之和；没有可靠时长时，按台词字数和动作节拍估算，结果在 4—30 秒之间；估不出来时按 15 秒处理并在代码块外说明。明确指定值冲突或台词确实超时，要指出并给最小修正方案，不删台词、不暗改指定时长。
- 默认连续同场镜头累计不超过 30 秒时合并，超过上限才按有效切点拆条；尊重用户明确逐镜生成或分条方式。每条 4—30 秒，末条不足 4 秒时调整切点；孤立短内容可用不改剧情的停顿/余波补足并说明。
- 时间戳只用整数秒。
- 术语括注只用全角（），例如“柔光（soft light）”，因为半角 () 在 Seedance 2.5 里表示音乐；【】只用作区块标题，因为【】在 Seedance 2.5 里表示字幕。
