## 0. 总控原则

### 0.1 特效注意力控制法

| 维度 | 定义 |
|------|------|
| 绝对主体 | 施法者 / 变身者 / 被空间规则影响的核心对象，每段唯一 |
| 核心动作 | 触发→传导→爆发→收束，每段只推进其中一个阶段 |
| 特效客体 | 光晕、碎片、藤蔓、黑洞、法相，必须作为主体状态变化的结果，不可独立乱动 |
| 背景边界 | 建筑、地面、天空只提供物理反馈和比例反差 |
| 镜头调度 | 所有运镜服务于主体与奇观的比例关系 |
| 时间轴 | 0-3蓄力 / 3-8爆发 / 8-12奇观展开 / 12-15收束 |

**三大禁止：**
- 特效在主体前自行扩散（主体必须是驱动源）
- 同一段内堆叠两个及以上大奇观
- 镜头在奇观高潮段随机漂移

### 0.2 VFX三层分层原则

```
第一层：核心介质 — 角色直接操控的能量/物质（雷电核心、剑气、火焰）
第二层：边缘粒子 — 包裹核心介质的高密度粒子光晕，掩盖帧间抖动
第三层：环境交互 — 特效与周围环境的可见反应（地面炸裂、空气扭曲、草木倒伏）
```

三层必须同时存在，单层特效 = 低质量。

### 0.3 光影绑定强制规则

所有特效必须有光源动机，特效自发光必须对主体面部、服装、地面产生可见色彩反射。

| 特效类型 | 光影反馈要求 |
|---------|------------|
| 蓝紫雷电 | 蓝紫边缘光打亮角色侧脸，地面间歇蓝白闪光 |
| 金红火焰 | 暖橙从下方打亮角色，周围烟雾染橙红 |
| 绿色植物/毒 | 冷绿漫反射覆盖场景，角色皮肤轻微绿调 |
| 白光法相 | 强逆光勾勒角色轮廓，场景整体曝光提升 |

## 1. 大招与终极法术特效

### 1.1 比例反差法则

法术力量感来源于"角色与奇观的尺寸差"，比例差越大，神圣感越强。

| 级别 | 奇观与角色比例 | 适用场景 |
|------|-------------|---------|
| 一般法术 | 奇观高度 = 角色 × 3-5 | 覆盖场景范围 |
| 大招级 | 奇观高度 = 角色 × 10-20 | 覆盖天际线 |
| 终极法相 | 奇观高度 = 角色 × 50-100 | 遮天蔽日 |

> 极端尺度反差（extreme scale contrast），高耸的神性奇观将人影衬得渺小，灵力显化达到建筑级体量，神祇般的压迫存在感

### 1.2 环境物理反馈链

法术释放必须触发多层环境反应，不能只有光效：

```
气压波 → 落叶/沙尘/水面向外扩散
电磁场 → 金属武器震颤，发丝末梢竖起
重力扭曲 → 碎石悬浮，水流倒流
温度场 → 近处火焰熄灭，远处空气热扭曲
```

> 冲击波（shockwave）向外横扫，碎屑在反转的重力场中悬浮不落，空气泛起热扭曲（thermal distortion），金属器物在电磁场中嗡鸣震颤

### 1.3 微观施法仪式

大招起势阶段必须包含手印/眼神/生理反应三联：

- **手印特写**：指节用力绷紧、皮肤纹理、指间气流凝聚可见
- **眼神异化**：瞳孔收缩或异色化（金瞳 / 银瞳 / 竖瞳）
- **生理反应**：太阳穴青筋轻跳、胸腔起伏加重、发丝被气场吹动

> 手印结成的大特写，指节绷紧到皮肤被拉出纹路，指间气流可见地凝聚收束，瞳孔竖裂异化，发丝在灵气风中根根扬起

## 2. 角色变身特效

### 2.1 抗融合轮廓锁定

变身过程最大失败风险：主体面部/身体与特效融合变形。

**锁定公式：**
> 建筑级精度的形象描述：[精确服装层次] + [发型结构] + [面部骨相]，三者在整个变身过程中必须始终清晰可辨，不被特效吞没

**强制保持元素：**
- 角色轮廓硬边：全程保持剪影边缘锐利（sharp silhouette edge），不与特效糊成一团
- 发型整体结构不在特效中消失
- 眼睛颜色/瞳孔形状（面部唯一识别锚点）

**粒子皮肤技术（掩盖帧间抖动）：**
> 高密度发光粒子紧贴角色骨架包裹成一层粒子皮肤（particle skin），粒子在剪影边界处最密，用以掩盖帧间抖动，同时保持身体结构清晰可辨

### 2.2 五大转化介质

| 介质 | 提示词写法 |
|------|------------|
| 碎片解体 | 身体碎裂成发光晶体碎片（crystal shards），每一片有各自独立的飞行轨迹，由外向内逐层解体 |
| 机械化 | 皮肤剥离露出内部齿轮机构，关节结构外露，金属外骨骼逐层浮现拼合 |
| 植物藤蔓 | 藤蔓自体内破出，叶脉沿皮肤表面蔓延生长，向草木形态有机转化 |
| 羽化飞升 | 发光白羽层层吞没身形，躯体在失重中消散，向天界飞升 |
| 丝带缠绕 | 光质丝带自四肢末端向内缠绕，在汇聚点完成形态替换，光流持续流转 |

### 2.3 双图首尾预设法

图生视频时必须设定精确起止状态：
- **起始帧**：变身前角色完整正常站立状态
- **结束帧**：变身后完成形态明确静态
- 文本描述同时写明：起始状态=[变身前外观] → 结束状态=[变身后外观]

## 3. 空间异变特效

### 3.1 黄金工作流（图生视频优先）

> **首选图生视频**，不要文生视频。原因：空间特效高度依赖初始构图与透视关系，文生随机性过高。

流程：
1. 先生成稳定的起始帧静态图（建筑/场景/角色位置精确）
2. 以该图为首帧生成视频，加入空间变形描述
3. 用尾帧锁定空间变形的最终状态

### 3.2 物理光学词库

|------|--------|
| 空间折叠 | 空间折叠（spatial folding），建筑平面向灭点方向弯折，非欧几何结构（non-Euclidean geometry） |

## 4. 诡异/超现实特效

### 4.1 空间拓扑变形

基于物理规律被撕毁的视觉系统。

| 手法 | 描述 | 提示词写法 |
|------|------|--------|
| 埃舍尔循环 | 楼梯无限上升，走廊无法到达尽头 | 埃舍尔式不可能建筑（Escher-like impossible architecture），楼梯无限向上延伸，走廊看不到尽头 |
| 莫比乌斯空间 | 地面即天花板，内外翻转 | 莫比乌斯式空间翻转（Möbius inversion），地面变成天花板，室内外互相翻转 |
| 非欧几何空间 | 平行线相交，直角变形 | 非欧几何空间（non-Euclidean space），平行墙面在远处相交，透视关系不可能成立 |
| 递归无限 | 场景内存在相同场景的缩小副本 | 递归无限空间（recursive infinite space），场景内套着同一场景的缩小副本，层层退行 |

### 4.2 材质异化

物质发生非自然状态转变，突破材质物理规律。

| 材质 | 异化方向 | 提示词写法 |
|------|---------|--------|
| 木/石 → 液态 | 固体流动 | 石头液化，固体以缓慢黏稠的方式流动，违背重力的液态岩石 |
| 水 → 固态阵列 | 液体刚化 | 水凝结成几何晶片阵列，瀑布在下落途中冻结定格 |
| 金属 → 有机生长 | 无机生命化 | 金属抽出有机卷须，钢铁如藤蔓般生长，无机物呈现生命体特征 |
| 布料 → 发光体 | 材质自发光 | 布料自体发光（bioluminescence），织物本身成为光源，纤维间透出流光 |

### 4.3 精神污染/故障恐怖

视觉系统的破坏性表达，用于心理崩溃、邪恶侵蚀、梦魇入侵场景。

**故障感 / 数字污染：**
> 现实故障感（glitch effect），画面浮出数字伪影，RGB 三通道分离错位，像素位移噪波，编码崩坏的块状破碎，数据损毁被实体化呈现

**双重曝光叠影：**
> 多重曝光叠影（multiple exposure），记忆残像如幽灵般重播，半透明人影重叠在现实画面之上

**镜像错位：**
> 镜像错位（mirror displacement），倒影脱离本体独立行动，影子与身体分离，镜中人拒绝复制现实中的动作

**人体解构：**
> 肢体沿违背关节结构的方向运动，身体朝向不可能成立，半透明皮肤下可见生理结构（限幻觉/法术场景，不做血腥暴力）

### 4.4 超现实模板库

**模板A：盗梦空间**

```
[0-3s] 固定镜头：常规古建场景，角色在庭院行走
[3-8s] 建筑开始缓缓折叠，远景高楼向上弯折90度，
```

**模板B：中式禁忌规则怪谈**

```
[0-3s] 固定镜头：古宅走廊，角色向前走，

[3-8s] 角色回头，走廊已经消失，只剩正前方无限延伸
```

**模板C：纯粹精神污染**

```
[0-3s] 角色面部特写，表情正常，背景正常
[3-8s] 画面边缘开始出现RGB色散，背景人物动作异常缓慢，
       角色眼白出现细微血丝纹路
[8-12s] 场景叠影加重，同一空间的多个时间状态同时显现，

[12-15s] 所有异常在一瞬间消失，场景恢复正常，

```

**模板D：时间冻结战术**

适用场景：高阶修仙者/时空系能力者的战术性时间冻结——非全场冻结，而是"冻结环境中特定元素"以创造战术优势。

```
[0-3s] 角色单手结印/握拳，瞳孔变色（银/金/异色），
       周围空气出现可见的"涟漪波纹"以角色为中心向外扩散
[3-8s] 涟漪所过之处，环境元素依次冻结停摆：
       飞溅的水滴悬停空中 → 飘落的叶片定格 → 对手动作被"卡住"但意识清醒（眼珠可转动）
[8-12s] 角色在完全冻结的环境中唯一自由行动：
       穿行于悬浮水滴之间，衣摆拂过静止叶片，
       或绕至被冻结对手身后变招蓄力
[12-15s] 角色收印/松拳，时间恢复流动，
       水滴落地、叶片继续飘落、对手反应过来但已中招/失去先机
```

**关键约束：**
- 冻结与解冻必须有"涟漪/波纹/光晕"作为传导媒介，不能瞬间全场静止
- 被冻结的角色眼珠/呼吸可以微动，保持"人"的质感而非雕塑
- 角色在冻结区行动时必须与环境互动（拨开悬浮水滴/身体绕过静止碎屑），强化时间差违和感

> 与 §3.2 物理光学词库中 `temporal freeze` 的关系：§3.2 的 `temporal freeze` 是静态描述词（用于环境定帧），本模板是战术动作模板（时间冻结 + 角色主动行动）。两者配合使用——先以 `temporal freeze` 描述环境状态，再嵌入本模板的战术行动逻辑。

**模板E：身外化身（仙侠分身术）**

适用场景：仙侠/修仙体系中的分身术、化身千万、残影迷惑。

```
[0-3s] 中景：角色双手结印，身体轮廓边缘开始出现"视觉重影"——
       如同热天柏油路上的蜃景，光线在角色身体边缘产生折射错位
[3-8s] 升格慢动作：从角色本体中"剥离"出1-3个完全相同的分身，
       分身从本体中走出的过程如同从水面中升起——先从背后/侧面走出，
       分身与本体的服饰、面容、姿态完全一致但动作可独立
[8-12s] 镜头拉远至全景：多个分身同时向不同方向行动
      （出击/防御/结阵），每个分身拖曳淡色残影轨迹，
       本体站在原地维持结印姿态
[12-15s] 分身依次化为光束缩回本体，本体松印睁眼，
       四周残留分身行动造成的环境痕迹（剑痕/冲击/风压落叶）
```

**核心约束：**
- 分身"剥离"必须有物理过渡介质（光线折射/水纹涟漪/烟雾抽离），禁止瞬切出现
- 每个分身必须有独立动作目的，不做"复制粘贴站桩"
- 本体在分身期间维持结印/定身姿态，不做同时行动（区分于克隆倍增）

> **与 §2.4 模板C 阴阳双生的区分**：阴阳双生是从影子中分裂出"相反形态"（镜像对立），身外化身是从本体中复制出"相同形态"（多个自己）。前者强调对立统一，后者强调数量压制。

## 5. 修仙VFX技术规范

### 5.1 三层分层执行细则

**第一层：核心介质（必须最先写）**

直接从角色身体/武器发出的能量本体：

| 修仙系 | 核心介质写法 |
|--------|------------|
| 剑修 | 凝实的剑气自钢刃向外延伸，压缩的能量刃口表现为可见的热扭曲 |
| 雷修 | 雷电核心光柱，等离子放电通道，空气电离泛出紫光 |
| 火修 | 燃烧核心火球，过热气体聚成球体，焰心呈白炽 |
| 冰修 | 冰晶晶格成形，绝对零度的冰核，霜纹自撞击点向外蔓延 |
| 毒修 | 高浓度毒雾，荧光绿气溶胶，接触到的表面出现腐蚀痕迹 |

**第二层：边缘粒子（必须包裹核心）**

> 高密度发光粒子光晕包裹住[核心介质]，粒子在边界处密度最高、向外逐渐弥散，靠这层粒子皮肤维持帧间连续性

**第三层：环境交互（必须有可见反应）**

> [核心介质]命中引发[地面炸裂/空气电离/水面震荡/草木倒伏]，次级碎屑各自弹出轨迹，冲击波环在烟尘中清晰可见

### 5.2 特效段落的描述配比

特效段写进【时间轴】时，按这个顺序铺，缺哪一环就会露馅：

```
[景别与运镜] + [角色姿态与位置] + [核心介质] + [边缘粒子] + [环境交互] + [光影绑定] + [时间节奏]
```

> 这不是独立的输出格式。**全项目唯一的输出格式是 `templates/标准输出模板.md` 的四区块**，本节内容一律并入其中的【时间轴】。
>
> 不写帧率、升格倍率、音效标注——模型没有这些控制接口，音效也是后期的事。慢速用视觉描述表达：「水滴逐颗可辨、衣料褶皱缓慢展开」。

### 5.3 光影绑定执行清单

每条提示词写完后逐项检查：

- [ ] 特效光源是否对角色面部产生色彩反射
- [ ] 地面/墙面是否有特效光的投影或色彩染色
- [ ] 烟雾/尘埃是否被特效光打亮或染色
- [ ] 角色轮廓是否有边缘光勾勒（防止融入背景）
- [ ] 特效最亮点是否与镜头焦点一致

### 5.4 真人写实特效物理化写法

真人电影感特效不能只写"光效"，必须写成摄影机可拍到的物理现象：

```
[小型/大型法术介质] + [光源性质] + [真实介质反应] + [材质反馈] + [主体绑定]
```

**禁用倾向：**
- 炫酷法术、华丽光效、强大灵力、仙气爆发、满屏能量、神秘光芒
- 巨大干净光环、完整发光法阵、大面积霓虹蓝光、游戏技能拖尾

> 禁的是**形容词式的空话**（"华丽""强大""炫酷"），不是粒子本身。§0.2 的三层分层和 §6.1 的粒子皮肤都要求高密度粒子，那是写清楚了介质、密度分布与环境反应的具体描述，与本节不冲突。

**优先写法：**
- 冷白逆光穿过烟尘，光线被水汽和灰尘削弱
- 银蓝冷光沿发丝边缘闪过，照亮睫毛、脸颊、袖口和湿石板
- 烟尘被高速法器切开一道极窄空隙
- 碎符纸、石粉、水汽被短促冷光照亮
- 衣袖、发丝、阵旗被冲击波或风压拉动
- 湿石板反射冷光，裂缝中残留微弱余光

**真人写实约束词：**
> 光在面部与衣料上的溢出符合真实光学，实拍质感的烟雾吞掉部分光晕，尘埃与水汽被冷调逆光照亮，光线穿过雾气不均匀衰减，布料质感可触，湿石板泛起反光，不出现干净的霓虹拖尾

### 5.5 精准小法器动作拆解

当法术目标很小（发绳、符纸、手腕、发簪、铃铛、剑穗）时，不要使用大飞剑、大光刃等大尺度法器；优先使用小型点状法器，并强制写清尺寸、轨迹、命中点和结果。

**小法器标准公式：**

```
[尺寸] + [材质] + [飞行轨迹] + [命中点] + [禁止误伤区域] + [物理结果] + [穿出/消散]
```

**示例：断束飞针**
> 一枚小型暗银墨蓝飞针从烟尘中高速掠来，约10厘米长、竹签粗细，三棱细锥形，外层贴合极薄冷蓝灵气膜；飞针以切线轨迹精准命中发髻根部浅蓝白发绳结，针尖只切断发绳纤维，不触碰皮肤、不削断头发；断裂布丝向两侧弹开，发髻轻微震动，几缕发丝被针风拉开，飞针穿过断口飞出画面。

**精准动作拆解顺序：**
1. 先锁定目标点：`镜头焦点锁定发髻根部浅蓝白发绳结`
2. 再写轨迹：`从侧后方/侧前方以切线轨迹掠过`
3. 再写接触：`针尖命中发绳结最紧的位置`
4. 再写排除：`不触碰头皮、脸部、脖颈，不削断发束`
5. 再写反应：`布丝弹开、发髻震动、发丝被风压拉开`
6. 最后写结果：`飞针穿过断口飞出画面，发绳尾端开始松开`

**头发散开写法：**
不要只写"长发散开"。必须写过程：
> 发绳断裂后，发髻外层先松动，几缕黑发从发髻边缘滑落，随后内层发束失去固定，一层一层垂下，被风压吹得凌乱铺向脸侧、肩线和纱袖。

## 6. 粒子/水墨系统

### 6.1 粒子皮肤技术

**核心目的**：高密度粒子包裹角色骨骼轮廓，掩盖视频生成的帧间抖动，让高速动作段保持主体稳定。

**标准写法：**
> 高密度发光粒子皮肤（particle skin）自头到脚包裹角色骨架，粒子在身体轮廓边界处最密、向外迅速稀疏，在整个运动过程中锁死剪影稳定

**粒子类型对应场景：**

| 场景 | 粒子类型 |
|------|---------|
| 修仙蓄力 | 白色/金色灵气粒子 |
| 邪修/魔化 | 黑紫碎裂粒子 |
| 水系法术 | 透明水雾粒子 + 折光 |
| 雷系法术 | 蓝白等离子粒子 |
| 武侠内劲 | 无色透明气流粒子（仅可见扭曲） |

### 6.2 水墨高粒子扩散系统

**适用场景**：国风水墨美学 + 高粒子扩散打斗的混合视觉风格。

**核心写法公式：**
```
[墨色粒子介质] + [扩散轨迹] + [水墨渗透效果] + [速度层次]
```

**墨色介质词库：**
> 水墨粒子爆散开来，能量拖尾呈书法笔触形态，墨色如在水中溶解般化开，墨烟在失重中缓缓膨胀

**扩散轨迹写法：**
> 墨粒沿运动轨迹拖曳成线，呈笔锋散开般的飞溅形态，自撞击点离心扩散，墨迹在空气中留痕不散

**水墨渗透效果：**
> 墨色渗入空气介质，边缘羽化晕开，模拟宣纸吸墨的纹理，湿墨自然洇散

**墨水化形模板（国风粒子变身）：**

适用场景：仙侠/古装中水墨系角色变身、化形、遁术。非西方粒子特效，而是中国传统水墨画的美学逻辑。

```
[0-3s] 角色立于画面中央，身体轮廓边缘开始出现墨色晕染，
       墨色从衣摆/袖口/发尾的边缘向身体中心渗透，
       如同墨水滴在宣纸上的扩散逻辑
[3-8s] 身体大面积化为墨色液态，角色形态逐渐解体为"人形墨迹"——
       但仍保留面部骨相轮廓（轮廓线以浓墨勾勒），
       墨团边缘有毛笔笔触的飞白和枯笔纹理
[8-12s] 墨团在空中重新凝聚，以"书法笔顺"的逻辑逐笔重构新形态：
       先写骨架（浓墨），再填血肉（淡墨），最后勾勒衣纹（焦墨/枯笔）
[12-15s] 化形完成，新形态角色出现，最后一滴墨从指尖滴落，
       在空中晕开成烟消散
```

**核心技法词库：**
> 水墨化形，以书法笔顺逐笔重构形体，宣纸洇墨的物理逻辑，湿墨积聚后向边缘羽化，枯笔的干涩边缘质感，飞白处墨粒飞散，浓淡墨层次分明

> **兼容性**：本模板与 §2.4 模板B "化形破茧"为同功能替代——化形破茧是西方光膜逻辑，墨水化形是东方水墨逻辑。根据角色/世界观选择对应体系。

### 6.3 运动模糊分层策略

| 层级 | 模糊程度 | 适用对象 |
|------|---------|---------|
| 零模糊 | 绝对清晰 | 角色面部、眼神 |
| 微模糊 | 极轻运动拖影 | 角色躯干、服装 |
| 中模糊 | 明显残影 | 武器轨迹、粒子尾迹 |
| 强模糊 | 大面积运动模糊 | 背景、次要环境元素 |

> 强制指令：运动模糊只作用于背景（motion blur on background only），角色面部与武器边缘始终锐利

### 6.4 三维分镜微雕法

每个特效镜头按四维拆解构建：

```
【时间片】    — 这0.5-3秒内只发生一件事（蓄力/触发/扩散/收束）
【物理动作】  — 角色/特效的物理状态（位置/速度/受力方向）
【运镜语言】  — 机位/景别/运动方式（固定/推进/环绕/拉远）
【物理介质】  — 特效与环境的接触材质（水/石/空气/金属/布料）
```

**示例拆解（雷击蓄力段）：**
```
时间片：0-2秒，蓄力凝聚
物理动作：角色静止，双掌前推，指间气流向心汇聚，头发末端竖起
运镜语言：低角度仰拍固定机位，缓慢推入至手部特写
物理介质：空气电离（蓝紫光晕），地面干燥石砖出现细微震动裂纹
```

## 7. 常见失败修复矩阵

| 问题 | 根因 | 修复方法 |
|------|------|---------|
| 特效光污染主体 | 特效亮度覆盖角色轮廓 | 加边缘光锁定：角色剪影在特效背景前保持锐利边缘 |
| 主体在特效中消失 | 无轮廓锁定 | 加粒子皮肤 + 服装/发型精确描述 |
| 奇观互相抢戏 | 同段塞入多个大效果 | 按时间轴拆分，每段只一个奇观阶段 |
| 变身后脸变形 | 无面部锁定词 | 加面部锁定：全程保持五官特征一致 [五官描述] |
| 法术像PPT贴图 | 缺少环境交互 | 补三层系统：核心介质 + 边缘粒子 + 环境反馈 |
| 特效无力感 | 无比例反差 | 加尺寸对比词：建筑/天际线作为参照物 |
