# 情感表演 Skill — 横屏真人影视

> 适用模型：Seedance 2.0 及同类视频生成模型
> 适用类型：横屏真人古装 / 仙侠 / 现代情感戏
> 核心目标：消除 AI 假感、塑料表情、悬浮感，输出可感知重量的真实演技提示词
>
> **写法约定**：本文件所有提示词条目均为**中文主干 +「中文（English keyword）」**格式，可直接誊入【时间轴】。运镜、布光、材质、VFX 四类专业术语附英文，其余一律纯中文，不写整句英文。
>
> **镜头约束**：近景表演必须与精确焦距和景深配套。中景及更近景别使用 85mm 以上，一个镜头只给一个焦距，并写清远机位、空间压缩、单一合焦平面和背景局部虚化；完整规则见 `references/镜头与灯光词典.md` §2.2。

---

## 0. 核心底层逻辑

**从"状态描述"走向"动作解构"**

AI 产生假感的根源：模型倾向生成绝对完美、静态悬浮的画面。

破解方式：提示词从形容词转变为动词 + 物理细节。

| 弃用 | 复用 |
|------|------|
| 他很悲伤 | 他紧抿双唇，双眼蓄满泪水，肩膀微微颤抖 |
| 她很紧张 | 她双手在桌下不自觉交替搓揉，迅速抬眼偷瞄后立刻将视线躲闪到水杯上 |
| 他很疲惫 | 他烦躁地扯开微松的领带，几缕碎发散落额头，下巴带着发青的胡茬 |

**两个关键概念：**
- 引入"时间流逝"：动作要有前后演变，不是一张静止表情
- 引入"物理重力"：角色必须有重力支撑点，身体在空间中有明确的承重逻辑

## 1. 微表情公式

**公式结构：** `眼部细节` + `视线方向` + `面部肌肉状态`

### 1.1 局部面部控制词库

**眼部：**
- 眼神空洞 / 视线失焦到聚焦
- 双眼蓄满泪水（不流下）
- 眼睑微垂 / 睫毛轻颤
- 眼眶泛红 / 眼下浮肿

**面部肌肉：**
- 紧咬牙关 / 咬肌微凸
- 眉头从紧锁到逐渐舒展
- 嘴角不自然地抽动
- 眉毛轻微上挑

**复杂情绪：**
- 强颜欢笑：嘴角勉强上扬，但眼神未跟上，眉头仍轻微皱着
- 极力克制：下颌绷紧，喉结微动，嘴唇用力抿住
- 破碎感：表情在微笑和崩溃之间撕扯，眼角溢出一滴泪但嘴角仍扯着弧度

> **"泄露点"（Leak Point）**：上述复杂情绪的本质是"整体控制但留一处破绽"——面部90%维持社交面具，仅通过一个微小的生理细节（眼眶红、喉结微动、指尖轻颤）泄露真实情绪。详见 §1.2 情绪过渡动态中的范例。

### 1.2 情绪过渡动态

**公式结构：** `初始微表情` + `情绪触发/内心活动` + `表情的动态演变`

拒绝脸谱化表情，通过情绪的动态切换拉高演技上限。

**范例：**
> ❌ 医生做完手术很累，后来放松了。
>
> ✅ 医生摘下口罩，眼神起初空洞地望向走廊深处，随着她深吸一口气，原本紧绷的眉头逐渐舒展，嘴角扯出一个疲惫但释然的微小弧度。

## 2. 肢体落地感

**目标：** 消除角色的悬浮感，建立真实的重量感和潜意识行为。

**公式结构：** `核心姿态锚点` + `潜意识微动作` + `与环境/道具的物理交互`

### 2.1 高频肢体词库

**局促/紧张：**
搓手、指尖摩挲、无意识地抠指甲、抬眼偷瞄、视线游移

**松弛/日常：**
挠脸颊、捋头发、揉捏后颈、重心偏移、懒散地靠住椅背

**疲惫/卸力：**
双手滑落、身体后仰、瘫软在椅背上、长舒一口气、脊背微驼

**愤怒/压制：**
手指无意识地叩击桌面、握拳松开再握拳、下颌前推、呼吸加重

### 2.2 范例

> ❌ 一个年轻人在餐厅相亲，他很紧张。
>
> ✅ 男生僵硬地坐在餐桌前，双手在桌下不自觉地交替搓揉，他迅速抬眼偷瞄了对面的女孩一下，又立刻将视线躲闪到桌面的水杯上。

## 3. 战损与瑕疵

**目标：** 赋予角色"故事背景"和"时间痕迹"，打破 AI 的绝对对称与平滑。

**公式结构：** `服装物理损耗` + `妆造/毛发的凌乱感` + `生理特征反应`

### 3.1 细节词库

**服装：**
- 起皱的衬衫 / 微松的领带 / 卷起一半的袖口 / 沾染灰尘的夹克
- 古装适用：袍角沾了一截泥水 / 腰封松动了半扣 / 发丝乱了一缕挂在脸侧

**毛发/妆容：**
- 散落的发丝、几缕贴在额头的碎发
- 发青的胡茬 / 斑驳的口红 / 出油的鼻尖

**生理反应：**
- 额头细密的汗珠 / 眼下淡淡的乌青
- 粗重的呼吸造成的胸腔起伏 / 鼻尖泛红 / 眼眶微红

### 3.2 范例

> ❌ 一个熬夜加班的帅哥总裁。
>
> ✅ 男人靠在真皮沙发上，原本一丝不苟的背头散落了几缕碎发，下巴带着发青的胡茬。他烦躁地扯开微松的领带，衬衫领口隐约可见褶皱，展现出一种高压下的极致疲惫感。

## 4. 各类情绪生理反应词库

### 悲伤/隐忍
眼眶泛红、鼻尖发红、睫毛轻颤、双唇微微颤抖、泪水在眼眶打转但未溢出、喉咙滚动像在压制哭腔、指尖悄悄攥紧衣角

### 愤怒/压制
咬肌微微凸起、太阳穴青筋轻跳、鼻孔轻微扇动、眼神锋利但嘴角维持着弧度、手指无意识叩击、呼吸节奏刻意放缓

### 恐惧/惊慌
瞳孔骤然放大、呼吸急促浅短、全身轻微僵直、眼神快速扫视四周、双手不自觉地抓紧眼前的东西、脊背贴住身后的墙

### 喜悦/克制
嘴角反复压住又翘起、眼角细纹微微显现、鼻翼轻微扇动、眼神亮起但故意别开、下意识咬住下唇

### 震惊/空白
表情骤然凝住不动、眼神失焦、张嘴但没有发出声音、身体的细微动作全部停止、随后某个细节动作（如手中的东西掉落）触发反应

### 疲惫/释然
眼皮沉重微垂、呼吸从浅变深变长、肩膀从绷紧到缓缓下沉、脊背弯曲、发出一声轻微的、几乎无声的叹气

## 5. 空间支撑点与机位规范

### 5.1 空间支撑点锁定

长视频或连续情感戏中，必须在提示词里锁定角色的重力支撑点，防止身体形变。

> 明确写法：**"他的右肘沉重地压在木质桌面上，支撑着倾斜的身体"**
>
> 不要写：**"他靠在桌子旁边"**（模型不知道支撑点在哪，容易飘）

**古装场景支撑点示例：**
- 单手撑住石栏，俯视庭院
- 背脊贴住冷硬的柱子，缓缓滑落
- 双膝跪地，双手握拳撑在地砖上

### 5.2 机位配合情感强度

| 情感强度 | 推荐机位 | 说明 |
|---------|---------|------|
| 微表情、细节情绪 | 特写 (Close-up) | 睫毛、汗珠、嘴角细节必须特写才可见 |
| 全身情绪、肢体动作 | 中景 (Medium Shot) | 能同时看到表情和肢体 |
| 崩溃/爆发 | 中近景 + 手持轻微抖动 | 增加不稳定感 |
| 压抑/克制 | 固定机位、慢推进 | 静止感强化内心张力 |

**微表情前置词（Seedance 使用）：**
> 皮肤质感超细腻，毛孔与绒毛可辨（ultra-detailed skin texture），写实的电影级布光

### 5.3 情绪表演注意力控制

- **绝对主体优先**：每个镜头只锁定一个情绪主体，多人同框时明确谁是表演中心
- **核心动作锚定**：一个镜头只服务一个情绪变化动作（忍泪 / 压抑呼吸 / 眼神回避 / 缓慢转身）
- **辅助动作从属**：微表情、呼吸、手部小动作、视线移动必须围绕核心情绪动作展开，不得抢戏
- **背景边界控制**：背景人物、环境摆设只承担氛围映射，不制造新的视觉主语
- **时间节奏四段化**：情感建立 → 情感发展 → 情感高潮 → 情感回落，每段只推进一个心理状态

### 5.4 自然主义手持对白（替代模式）

适用场景：日常感、亲密对话、即兴感强的文戏段落。当正反打的"设计感"会破坏戏的真实感时使用。

**核心**：用轻微手持呼吸感替代精确正反打切镜，让观众感觉自己就在现场。

**提示词写法：**
```
手持镜头（handheld）带轻微呼吸般的起伏，纪实感的对话覆盖方式。
镜头随对话流动在两人之间自然转移注意力，不做硬切。
柔和的环境光，浅景深（shallow depth of field），亲密的中近景。
```

**古装适配**：把"环境光"替换为具体动机光源（烛火/月光/炉火），保留手持呼吸感和自然切换。

> **兼容性说明**：本模式与 `skills/分镜.md` §2 正反打体系为替代关系，非互斥。判断标准——有明确攻防关系、权力不对等的对话 → 正反打；日常感、平等关系、即兴感强的对话 → 自然主义手持。

## 6. 常见失败修复

| 问题 | 修复方法 |
|------|---------|
| 表演写得浅、只有一句"神情复杂" | 抽象标签一律拆成生理动作：眼睑/睫毛/视线落点/咬肌/喉结/鼻翼/呼吸/指尖/重心。表演篇幅占该段一半以上（见 `references/Seedance规范.md` §七 预算分配） |
| 表情像面具、不动 | 加情绪过渡动词（从紧锁到舒展、从空洞到聚焦） |
| 角色像悬浮在空中 | 补空间支撑点：明确哪个部位在承重 |
| 微表情看不见 | 前置特写景别 + 皮肤质感词 |
| 表情突变没有过渡 | 用"随着……逐渐……"时间流逝句式描述动态变化 |
| 表情太夸张像漫画 | 删除形容词，换成具体肌肉/部位描述 |
| 多人同框焦点混乱 | 明确主体，背景人物加"静止"或"低幅度"约束 |

## 7. 慢燃浪漫场景模板

适用场景：古装/仙侠中克制、缓慢升温的情感戏（眼神交错、距离试探、未说破的牵绊）。

**核心原则：**
- 爱意不靠台词，靠物理距离的变化和视线的"不敢对视→短暂交汇→迅速躲开→再次偷看"
- 每个阶段只推进一个心理距离的变化
- 不写"他们相爱了"，写两人之间的距离从三尺缩短到一尺

**15秒四段结构：**

```
[0-3s] 距离建立：
固定中景，两人在同一空间但保持礼貌距离（三尺以上）。
各自做手头的事（煮茶/翻书/擦剑），无明显交流，
但一人（主体）的视线在对方不注意时短暂停留后迅速移开。

[3-8s] 视线交错：
近景切主体面部，对方说了某句话或做了某个动作，
主体眼神刚亮起就被压回去，低头掩饰嘴角微动。
升格慢动作捕捉睫毛轻颤和喉结微动。

[8-12s] 物理靠近：
中景，其中一人（客体）自然地走近一步，主体身体微僵但未后退。
两人距离缩短至一尺以内，客体伸手——可能是一个慢速的整理衣领/拂去发间落叶/递来茶杯的动作。
主体屏息，指尖在身侧悄悄攥紧衣角。

[12-15s] 余波定格：
客体退开，主体缓缓呼出一口气，视线追随客体背影，
嘴角反复压住又翘起，手指慢慢松开攥皱的衣角。
柔光逆光勾勒轮廓，留白结束。
```

> **古装适配**：动作替换为古装日常（研墨/斟茶/抚琴/舞剑），肢体接触替换为衣袖轻触/发丝拂过/指尖短暂相触即离。避免现代亲密动作。
