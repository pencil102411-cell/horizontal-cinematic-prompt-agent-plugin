# 分镜 Skill — 横屏真人影视

> 适用模型：Seedance 2.0 及同类视频生成模型
> 适用类型：横屏真人古装 / 仙侠 / 武侠短剧
> 核心目标：用导演视角设计镜头序列，每一镜都服务于信息、情绪、人物关系或动作节拍的变化
>
> **写法约定**：本文件所有提示词条目均为**中文主干 +「中文（English keyword）」**格式，可直接誊入【时间轴】。运镜、布光、材质、VFX 四类专业术语附英文，其余一律纯中文，不写整句英文。

---

## 参考标尺

三组电影视觉系统，用于校准镜头判断：

- **《绝命毒师》** → 静止镜头力量、负空间、构图压迫、听者反应、节奏呼吸
- **《满江红》** → 低饱和、高级灰、封闭空间压力、弱暖光、暗部层次
- **《凡人修仙传》** → 文戏克制、武戏动作链条、特效前摇与余波、比例反差

## 0. 输入自适应

本 Skill 接收三种输入，自动切换处理深度：

| 输入类型 | 处理方式 |
|---------|---------|
| 单镜头需求 | 直接定起幅→展开→落点 + 运镜 + 风险规避 |
| 单场戏 | 先判断场戏核心，再建立空间轴线，最后拆镜 |
| 多场戏/剧本片段 | 先自动切场（依据：空间变化/时间变化/人物组合变化/冲突对象变化/情绪阶段变化），再逐场拆镜 |

> **本 Skill 不产出交付物。** 无论哪种输入，拆镜结果一律并入 `templates/标准输出模板.md` 四区块中的【时间轴】。不单独交付分镜表——景别、精确焦距、景深、机位、运镜、站位、情绪，全部化进时间轴各段的自然语言里。

**信息不足时的处理：** 先做合理导演判断并标注，不索要完整表单。画幅由用户在模型界面选择，不写进提示词；未说明风格时默认低饱和、克制、电影感。精确时间轴缺少总时长时只问时长一个问题；用户要求先出则按 15 秒内部工作基准编排，并在代码块外说明。

室外戏拆镜时把天气变化当作叙事动作：先确定风雨雪雾的触发与方向，再安排它对人物、场景/道具和光影的可见反馈。不能把天气只放在开场空镜，后续人物镜头却完全不受影响；细则见 `references/室外环境动力.md`。

## 1. 总控原则

### 1.1 分镜不是逐句配图

不要看到一句台词就切一个镜头。切镜前先判断：

- 这一刻观众需要看到什么新信息？
- 情绪有没有升级、转向或停顿？
- 人物关系有没有变化？
- 画面重点是否从"人"转向"动作 / 道具 / 证据 / 空间结果"？
- 这一刀切过去是否比不切更有效？

**答不上来就不要切。长镜头优于无意义切镜。**

### 1.2 无效切镜识别

以下情况都是无效切镜，必须避免：

- 上一镜和下一镜信息差不多
- 景别变了，但情绪没有推进
- 只是为了"有变化"而换角度
- 为了正反打而硬切正反打
- 为了套"全景 → 中景 → 近景 → 特写"公式而切
- 一句台词一镜头，导致镜头碎但没有导演逻辑

### 1.3 景别跳跃规则

"跳景别"的目的是避免相邻镜头太相似，让观众明确感到画面重点改变了。但它不是死规则：

- 双人中景 → 单人近景：重点从人物关系变成情绪反应
- 单人近景 → 手部/道具特写：重点从人物变成证据或关键物件
- 近景 → 远景：重点从个人情绪变成空间结果或命运状态
- 中景 → 中景可以成立，前提是机位、视角、人物关系或情绪重心明显变化
- 连续两个差不多的中景：应该删除一个或重新设计切镜理由

**真正的规则不是必须跳景别，而是不能无效切镜。**

### 1.4 镜头必须有情绪

每个镜头必须写清楚情绪目的。不要只写"中景，A在左，B在右"，要写"中景，平视，A左B右，表现出A压迫B、B处于弱势"。

| 镜头方式 | 常见情绪作用 |
|---------|------------|
| 平视双人中景 | 建立关系、对峙、空间清楚 |
| 略低角度拍强势者 | 压迫、威胁、权力上位 |
| 略高角度拍弱势者 | 羞辱、无助、被审视 |
| 侧面近景 | 动作方向清楚，适合耳光、推搡、拔剑 |
| 单人近景 | 情绪反应、表情变化、心理压力 |
| 局部特写 | 证据、痛感、道具、关键动作 |
| 背面远景 / 纵深远景 | 孤立、离开、被带走、命运落定 |
| 过肩镜头 | 对话压力、视线关系、正反打 |

## 2. 正反打规则

### 2.1 正反打仅在以下情况使用

- 对话双方有明确攻防关系
- 一方施压，另一方承受
- 观众需要看说话者和听话者的反应
- 角色之间的权力关系、情绪变化需要通过视线来表达

不要为了"看起来专业"硬做正反打。

### 2.2 正反打前必须先建立轴线

在正反打之前，先用一个关系镜头建立：

- 谁在左，谁在右
- 两人面对方向
- 谁强势，谁弱势
- 空间关系是否清楚

**之后的正反打必须保持这个方向，不要让角色左右乱跳。**

### 2.3 正反打基本结构

1. **关系镜** — 交代双方站位和权力关系
2. **正打强势者** — 看施压、质问、攻击
3. **反打弱势者** — 看承受、退缩、解释、沉默
4. **关键细节** — 手、道具、证据、伤口、动作
5. **回到关系镜** — 看结果、命令、距离变化或权力落定

## 3. 对话戏拆分方法

### 3.1 判断情绪驱动者

有时候说话的人不是最重要的，听话人的反应才是重点：

- A在骂人，B被羞辱但忍住 → 重点可能是B
- A说出秘密，B的震惊反应才是镜头重点
- A平静说话但话语在压迫B → 切B的反应
- 两人真正交锋时 → 才适合正反打来回切

### 3.2 台词合并与拆分

| 判断 | 处理 |
|------|------|
| 台词只是继续同一种压迫 | 合并，不切 |
| 台词造成新的反应 | 应该切 |
| 台词带来证据、动作或转折 | 应该切 |
| 台词从质问变成宣判 | 应该切 |
| 台词从解释变成求饶 | 应该切 |

### 3.3 对话戏机位选择

参照 [references/镜头与灯光词典.md](../references/镜头与灯光词典.md) 中情绪-运镜-布光组合：

- **压抑/克制**：慢速推入 + 伦勃朗光 + 柔光
- **对峙/压迫**：越肩跟拍 + 侧光硬光
- **崩溃/爆发**：中近景 + 手持轻微抖动 + 顶光
- **柔情/亲密**：固定机位 + 柔光 + 逆光轮廓

## 4. 动作戏拆分方法

### 4.1 动作链法则

动作戏不能只写结果，必须写动作链条：

```
起手 → 发力 → 接触 → 结果
```

- ✅ "他蹬地发力，身体冲出，手伸向她，抓住她手腕，两人落地"
- ❌ "他飞身救下她"

### 4.2 动作镜头常用结构

1. 准备/起手
2. 发力/冲击
3. 接触/高潮
4. 结果/反应

### 4.3 动作戏机位选择

| 动作类型 | 推荐机位 |
|---------|---------|
| 单人突进 | 略低角度 + 越肩跟拍 |
| 受击/被压制 | 略高角度 + 受击跟随 |
| 双人对攻 | 侧面镜头 + 中景跟随 |
| 群攻/包围 | 广角全景 + 环绕运镜 |
| 轻功/飞行 | FPV + 低角度仰拍 |

详见 [skills/动作戏.md](动作戏.md) 镜头调度字典。

## 5. 景别选择规则

### 5.1 大远景 / 远景

用于：交代空间、人物渺小、孤立/离开/命运感、多人站位或空间压迫

不要滥用在普通对话里。

### 5.2 全景 / 中全景

用于：建立人物站位、看清两人距离、身体姿态、建立基本空间关系

适合开场关系镜。

### 5.3 中景

用于：对话、冲突中的身体姿态、角色之间权力关系、一方指责一方退缩、动作和台词同时需要被看清

中景是对话戏主力，但不能连续滥用。

### 5.4 中近景 / 近景

用于：情绪靠近、角色解释/忍耐/求饶/压迫、看清上半身和表情、正反打中的单人镜头

### 5.5 特写

用于：关键表情、伤口/手/道具/证据、一句话造成的心理冲击、情绪爆发点

**特写要珍惜，不能乱给。** 没有"视觉证据"或"强情绪变化"时不要硬切。

### 5.6 大特写

用于极强强调：眼睛、嘴唇、手指、关键物件一小部分

**大特写必须有强烈叙事理由。**

## 6. 机位与角度规则

| 机位 | 作用 | 拍谁 |
|------|------|------|
| 平视 | 客观、稳定、建立关系 | 普通对话、空间说明 |
| 略低角度 | 压迫、威胁、权力上位 | 强势者、审问者、攻击者 |
| 略高角度 | 羞辱、无助、被审视 | 弱势者、受害者、求饶者 |
| 侧面镜头 | 动作方向清楚 | 耳光、推搡、拔剑、转身离开 |
| 过肩镜头 | 对话压力、视线关系 | 正反打、攻防关系 |

### 6.1 POV第一人称子系统

POV（Point of View）不是一种"运镜"，而是将观众置入角色视觉感知系统的摄法。每种 POV 对应不同的信息策略和约束。

**四种 POV 类型：**

| POV 类型 | 视觉特征 | 叙事功能 | 约束 |
|---------|---------|---------|------|
| **纯视觉 POV** | 镜头=角色眼睛所见，含眨眼/视线模糊/血流视野等生理反馈 | 观众完全代入角色感知，适合被突袭、中毒幻觉、濒死体验 | 全程不能出现角色自己的脸/身体，只能出现手部入画 |
| **越肩 POV** | 镜头在角色肩后，角色头/肩在前景，观者与角色朝向一致 | 带入角色立场，适合对话压迫、对峙、观察场景 | 前景角色只能出现后脑/肩部轮廓，不能遮蔽画面重点 |
| **半主观 POV** | 镜头在角色近侧（脸旁/耳边），角色半脸入画，随其呼吸微晃 | 共情但不完全代入，适合犹豫、暗中观察、战术判断 | 角色面部只能侧入画，不能正对镜头 |
| **全主观幻想 POV** | 角色"想象/回忆/幻觉"的所见，带失真/色彩偏移/叠影等非常规视觉 | 传达角色的内在心理状态，适合闪回、噩梦、精神污染 | 必须通过色彩偏移、焦点异常、画面叠影与"现实POV"明确区分 |

**POV 使用规则：**
- POV 镜头不可超过整场戏的 40%，多用于关键情绪节点而非全程
- 从一个角色的 POV 切到另一个角色的 POV，中间必须有"返回客观镜头"作为过渡
- 纯视觉 POV 和越肩 POV 不可连续交替（会导致观众空间位置混乱）
- 首次建立 POV 时必须用一个客观镜头交代"谁在看"（反打角色面部），再切入 POV

**POV 提示词速查**（中文主干，术语附英文）：

- **纯视觉 POV**（first-person POV）：镜头即角色双眼所见，含自然眨眼、余光模糊、呼吸在镜头上结的雾气
- **越肩 POV**（over-the-shoulder POV）：角色肩部与后脑在前景，观众与角色朝向一致
- **半主观 POV**（intimate side-angle POV）：角色侧脸在画面边缘，镜头随其呼吸轻微起伏
- **全主观幻想 POV**（subjective reality POV）：色彩偏移失真，画面带记忆残影叠加，梦境逻辑

## 7. 类型场景分镜策略

### 7.1 对话/对峙场景

- 判断情绪驱动者 → 建立轴线 → 正反打结构
- 镜头节奏：慢、稳，以情绪变化为切镜依据
- 参照：本文件对话戏拆分 + [skills/情感表演.md](情感表演.md)

### 7.2 动作/打斗场景

- 动作链必须完整（起手→发力→接触→结果）
- 每个镜头锁定一个视觉锚点（主攻者/受击者/追逐目标）
- 15秒动作请求可参考四段：0-3起势 / 3-8爆发 / 8-12变招 / 12-15收束；其他时长按实际节拍重排
- 参照：本文件动作戏拆分 + [skills/动作戏.md](动作戏.md)

### 7.3 特效/法术场景

- 按四阶段拆分：蓄力→爆发→奇观展开→收束
- 每段只能一个奇观阶段，禁止堆叠
- 主体必须在特效中保持轮廓锁定
- 参照：[skills/特效戏.md](特效戏.md)

### 7.4 情绪/表演场景

- 眼睛永远是第一镜头
- 辅助动作从属核心情绪变化
- 参照：[skills/情感表演.md](情感表演.md) + [references/镜头与灯光词典.md](../references/镜头与灯光词典.md)

### 7.5 节奏曲线设计

每场戏拆镜前先画一条单句节奏线，确保整场戏有呼吸而非平均用力：

> 铺垫 → 压迫/靠近 → 停顿/留白 → 转折/爆发 → 余波/收束

- **文戏**：慢压为主，局部停顿蓄力，爆发点克制但精确
- **武戏**：慢蓄力→快发力→命中停顿→反馈爆发→余震回落
- **特效戏**：微观前摇→空间异动→比例反差→爆发→余波空镜

每个镜头必须落在这条线的某一节点上。如果连续三个镜头处在同一个节点（如"一直压迫"），检查是否需要合并或插入停顿。

### 7.6 空镜与转场规则

空镜不是风景装饰，只能承担以下功能之一：

- 承接人物心理（刚被抛弃的角色离开后的空椅子）
- 传递空间压力（封闭走廊、高墙、窄巷）
- 暗示关系变化（桌上未被拿走的信物）
- 制造情绪余波（战斗后缓慢落下的碎屑）
- 为下一轮爆发蓄力（暴风雨前的寂静水面）
- 时间或场景转换（光线穿过灰尘的过渡）

**每个空镜必须回答：** 承接上一镜什么情绪？让观众意识到什么变化？如何连接下一镜？答不上来就删除。

**转场方式速查：**

| 转场 | 情绪功能 |
|------|---------|
| 硬切 | 节奏紧凑、冲突升级 |
| 渐变/淡入淡出 | 情绪过渡、时间流逝 |
| 叠化 | 回忆、梦境、双重时空 |
| 黑场 | 场景终结、重大转折 |

### 7.7 短剧感风险排查

输出前逐项检查以下"短剧通病"：

- [ ] 是否一句台词一镜？
- [ ] 是否开场过早给特写（未建立空间关系前）？
- [ ] 是否正反打机械化（未建立轴线就正反打）？
- [ ] 是否空镜无效（无功能、纯装饰）？
- [ ] 是否情绪过满（所有镜头都100%强度）？
- [ ] 是否运镜炫技（镜头动但信息没变）？
- [ ] 是否动作/特效缺少前摇和余波？
- [ ] 是否节奏无呼吸（全程平或全程炸）？

## 8. 子弹时间变速法（进阶附录）

子弹时间不只是一句 `bullet time` 描述词，而是一种变速结构。

### 8.1 变速节奏公式

```
正常速度(铺垫) → 极端慢动作(子弹时间聚焦点) → 正常速度(结果)
```

**核心**：子弹时间的美学力量来自于"极快动作被极端慢放"——先建立高速预期，再用升格打破预期。

### 8.2 四种子弹时间应用场景

| 场景 | 子弹时间聚焦 | 慢到什么程度（写进提示词的说法） | 持续时间 |
|------|------------|--------------------------|---------|
| 兵刃碰撞瞬间 | 剑刃接触点火花迸发 | 火星逐颗可辨，能看清每一粒的飞行轨迹 | 1-2秒 |
| 致命一击 | 武器命中前一寸的悬停感 | 武器停在离面门一寸处，刃口反光的移动清晰可见 | 2-3秒 |
| 多人合击同时爆发 | 多个命中点同时展开 | 几个命中点的冲击几乎同时凝住，衣料褶皱缓慢展开 | 2-4秒 |
| 角色穿越粒子/碎片/水滴 | 碎片悬浮定格，角色穿行其中 | 碎片近乎静止悬在空中，只有角色以可察觉的速度移动 | 3-5秒 |

> **不写「20-30x升格」这类倍率。** 模型没有帧率控制接口，倍率数字进了提示词就是无效 token，白占字数预算。一律用上表右侧那种「能看清什么」的视觉描述——表达等价，且模型真的能执行。

### 8.3 提示词变量模板

```
[正常速度段 0-Xs]：
[角色动作]以真实速度进行，[环境反馈]同步全速运动。

[子弹时间段 X-Ys]：
画面渐变进入极慢速（bullet time），速度过渡连续不突变。
[聚焦对象]悬停在动作中途：[详细描述被冻结的瞬间状态]。
[角色]在凝住的[碎片/水滴/火花]之间穿行，是画面里唯一以可察觉速度移动的元素。
每一粒[碎片/火花/水滴]都单独可辨、边缘锐利，悬在半空。

[恢复正常段 Y-15s]：
慢速释放，所有悬停元素同时完成各自的轨迹，[结果描述]。
```

### 8.4 约束

- 每场戏子弹时间最多使用 2 次，超过则失去冲击力
- 升格段和正常段之间必须写明变速过渡（speed ramp transition），速度渐变不可突变
- 子弹时间段的焦点对象必须是前景的"碎屑/液体/火花"中至少一种，空背景慢放无意义
- 若与 `skills/动作戏.md` 模式B（瞬移高速连招）配合：子弹时间用于蓄力段，高速残影用于爆发段

### 台词时值参考

分镜"时长"列的计算依据。按台词字数和语速估算镜头时长：

**标点不计入字数。**

| 语速 | 换算 | 示例 |
|------|------|------|
| 慢速 | 1秒2字 → 每字0.5s | "你在怕什么"（5字）→ 约2.5秒 |
| 中速 | 1秒3字 → 每字≈0.33s | "你到底想怎么样"（7字）→ 约2.5秒 |
| 快速 | 1秒4字 → 每字0.25s | "让开别挡我的路"（7字）→ 约1.8秒 |

**时值计算规则：**
- 无台词镜头：纯动作/反应/空镜，按叙事需要估算（2-5s）
- 多句台词连续：累计字数后按语速换算，中间加0.3-0.5s停顿
- 情绪停顿：爆发前、情感释放后，额外加1-2s反应时间
- 同一场景内语速保持一致，语速变化应有明确情绪动机
