# 注意力控制法则 — 通用六维框架

> 所有 skill 共享的注意力控制底层方法论。模型注意力有限，必须通过严格层级划分，将90%注意力锚定在"绝对主体"和"核心动作"上，其余元素必须被明确降级或弱化。

---

## 六维框架

### 1. 确定绝对主体

先明确谁是画面的视觉中心。在多角色场景中，必须为主次角色分配严格的注意力权重。

- 谁是画面主体（占70-90%视觉注意力）
- 谁只是客体、陪体、背景
- 多角色同框时明确主次

**禁止：** 多个主体争抢同等注意力，导致五官融合、肢体错乱或动作主次不清。

### 2. 锚定核心动作

一个镜头只能有一个核心动作。所有辅助动作必须围绕核心动作展开且符合物理逻辑。

- 辅助动作：服务于核心动作（手部微调、衣摆飘动、重心微移）
- 禁止：与核心动作无关的突兀动作，抢夺模型注意力导致形变

### 3. 界定画面边界

给所有非主体元素定规矩，锁死干扰权限。

| 客体类型 | 约束方式 |
|---------|---------|
| 背景客体（建筑、天空） | 静止或极弱动态 |
| 互动客体（对手、路人） | 动作幅度受限，服务主体 |
| 环境物件（桌椅、道具） | 除叙事需要外不赋予动态 |

### 4. 规划镜头调度

镜头是观众的眼睛，运动必须围绕主体展开。必须明确：

- 镜头跟谁走
- 镜头从哪到哪
- 速度如何变化
- 焦点锁在哪
- 主体在画面中的位置（居中/偏左/偏右/前景压住）

**禁止：** "镜头动一动""拉近一点"等模糊指令。

### 5. 设定光影色彩

光影和色彩服务主体，不只是装饰。必须说明：

- 主体由什么光源照亮（光源必须有物理动机）
- 背景为什么被压暗或弱化
- 哪些颜色属于主体焦点，哪些只做气氛

### 6. 把控时间节奏

视频提示词必须按时间拆段，明确状态演变：

- 哪一秒谁先入画
- 哪一秒镜头开始动
- 哪一秒动作起手
- 哪一秒动作落点完成
- 哪一秒进入回落/余波
