# 室外环境动力 — 风雨雪雾与人物反馈

> 室外戏按需读取。目标不是罗列天气，而是把环境变化写成可见、连续、会作用于人物和场景的事件。

## 一、最低交付要求

只要场景出现风、雨、雪、雾、扬尘、日照突变或水汽变化，每个相关镜头至少写清：

1. **环境本体**：方向、强弱、密度或变化趋势
2. **人物反馈**：衣摆/发丝/皮肤/呼吸/眨眼/重心/步态中至少一项
3. **场景或道具反馈**：树叶、草木、积水、檐铃、灯笼、帷幔、旗帜、纸张、兵器水痕等至少一项
4. **光影反馈**：反光、阴影软硬、能见度、体积光、色温或亮度变化；只有确实可见时才写

至少命中“人物反馈”和“场景/道具/光影反馈”中的两类。不要只写“刮风”“下雨”“雪很大”。

## 二、因果链写法

使用这条顺序：

```text
环境触发 → 传播路径 → 人物/场景受力或受湿 → 可见反应 → 稳定或回落状态
```

例：

> 一阵侧风从廊外穿过，先压弯庭中竹叶，再掀起玲珑右侧鬓发和外层纱袖；她眯起迎风侧的眼睛，肩线略向左抵住风力。桌上薄纸被吹起一角后压回，灯笼向同一方向摆动两次，风势随即减弱。

这类因果链能让风向、受力方向和动作节奏一致，避免人物、植被和道具各自乱动。

## 三、常用环境映射

| 环境 | 人物可见反馈 | 场景/道具反馈 | 光影与材质反馈 |
|------|--------------|---------------|------------------|
| 微风 | 发梢和最外层轻纱小幅同向摆动，呼吸基本不变 | 叶尖、帷幔边缘、香烟轻偏 | 树影缓移，反光变化很小 |
| 阵风 | 发束、披帛、宽袖先后受力，人物眯眼、压低重心或抬手遮挡 | 枝叶成片翻面，旗幡/灯笼产生延迟摆动，尘土沿地面推进 | 云影或遮挡光快速扫过，轮廓光短暂增强/减弱 |
| 小雨 | 睫毛和鬓发逐渐挂水，肩背衣料颜色加深 | 青石出现散点湿痕，檐口连续滴水，水面形成细密涟漪 | 地面反射增强，远景对比度轻降 |
| 暴雨 | 发丝贴脸，衣料吸水增重，人物缩肩、眨眼或逆雨艰难移动 | 积水被雨点击碎，屋檐形成水帘，旗幡沉重甩动 | 能见度下降，逆光雨丝和水雾形成可见光束；避免无来源闪光 |
| 飘雪 | 雪落在发肩并逐渐积薄层，呼气成白雾，手指动作略僵 | 屋脊、枝条、地面积雪随时间增厚，脚步压出连续足印 | 冷白漫反射抬亮暗部，轮廓边缘变柔 |
| 雾 | 人物远离镜头时轮廓逐层变淡，呼吸与湿冷反应按需出现 | 建筑、树林按距离分层隐没，雾沿地势缓慢流动 | 对比度与饱和度随距离下降，光束只沿真实光源方向出现 |
| 扬尘 | 人物侧脸避尘、屏息或抬袖遮挡，衣角被气流带动 | 沙尘贴地卷行，碎叶和纸屑沿同一路径移动 | 逆光勾出颗粒层，远景偏暖灰并降低清晰度 |

## 四、连续性与镜头尺度

- 同一场戏锁定风向、降水方向、地面湿度、积雪厚度和人物湿身/沾尘程度；除非时间轴明确写出变化原因
- 环境先作用于迎风/迎雨面，人物衣发与道具遵循相同方向；不同重量的物体允许出现合理延迟
- 雨雪会累积，不能上一镜湿透、下一镜恢复干燥；镜头切换时保留发丝贴附、衣料颜色、脚印和水痕
- 大远景写云层、林海、雨幕、地表和群体受力；中景写衣摆、步态和附近道具；近景/特写写睫毛水珠、皮肤湿度、发丝贴附、呼吸和细小光影
- 环境变化服从主体注意力：每段只突出一个主要天气事件，其余反馈简写，不能让落叶、雨滴和云层同时抢戏

## 五、时间轴短句模板

```text
[方向/强度]的[风雨雪雾]从[来源]进入画面，[传播路径]；先作用于[场景物]，再带动[人物衣发/动作]，[人物生理或重心反馈]；[地面/道具/光线]出现[可见变化]，到段末[稳定或回落状态]。
```

写完后检查：如果删掉天气名词，句子里是否仍能通过衣发、地面、道具和光线的变化看出天气。看不出来，就说明环境尚未真正进入画面。
