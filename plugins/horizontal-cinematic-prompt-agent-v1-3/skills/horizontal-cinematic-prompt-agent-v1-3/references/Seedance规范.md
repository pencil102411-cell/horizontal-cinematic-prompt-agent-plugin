# Seedance 2.0 生成规范 — 横屏真人影视

> 所有 skill 共享的模型技术约束与输出规范，不单独使用。

---

## 一、模型能力边界

| 能力 | 规格 |
|------|------|
| **单次生成时长** | **≤15 秒**（模型后续升级将放宽至 30 秒，届时改此处数字即可） |
| 图片参考 | ≤9 张 |
| 视频参考 | ≤3 个，≤15s |
| 音频参考 | ≤3 个，≤15s |
| 总文件数 | ≤12 个 |

**拆条规则：** 单条提示词时长不得超过上述上限。超出的场次必须按镜头或叙事节拍拆成多条，在代码块外写清拆点；各条沿用同一批 @资产与同一套光影设计，接续时空间关系和光位才不跳变。

**限制：** 不支持写实真人脸部素材上传。角色一致性通过固定资产图 + 提示词约束实现。

### 运镜与切镜能力（不构成约束，勿据此拆镜）

Seedance 2.0 在运镜和镜内切换上能力很强，**以下全部可直接执行，不需要为"好不好生成"做任何妥协**：

| 类型 | 说明 |
|------|------|
| 复合运镜 | 推/拉/摇/移/升降/环绕任意叠加，如"拉+旋转+焦点转移"同时进行 |
| 镜内切镜 | 一条提示词内多次切换景别与机位，切点丝滑，无需拆成多条 |
| 长镜动作 | 单镜内完成多个攻防回合，连贯度好，长镜打斗是加分项而非风险 |
| 大幅度运镜 | 特写起幅→快速拉起上摇→鸟瞰全景→平移跟人，一镜到底成立 |
| 变速 | 同一镜内实速与慢动作往返切换可执行 |
| 特效密度 | 打斗与特效是模型强项，多发生点、多层粒子同镜不构成负担 |
| 短镜 | 1-2 秒的镜头同样能出有效画面 |

**因此：**

- **拆镜时，不得以"模型撑不住""执行不了""复合运镜风险高"为由拆镜或简化运镜。** 拆镜只能基于叙事逻辑、物理连续性、观众注意力这三类理由
- 唯一的硬拆条依据是 **≤15 秒时长上限**，与画面复杂度无关
- 仍需改写的只有**没有控制接口的参数**：帧率、升格倍率、分辨率、精确圈数（如"翻转两圈半"）——这类改成"能看清什么"的视觉描述，而不是降低运镜难度

## 二、提示词核心公式

```
【风格】+【素材引用】+【主体动作/状态】+【景别/精确焦距/景深】+【机位/运镜】+【光影动机】+【环境运动与反馈】+【稳定性约束】
```

**关键原则：有素材则简，无素材则详。** 如已有角色/场景资产图，提示词只写引用 + 当前镜头补充（动作、情绪、光线），不重复五官、发型、建筑布局。没有资产图时才展开完整描述。

---

## 三、时间轴强制规范

每个视频提示词必须按时间段拆解，每段必须包含：**景别/精确焦距/景深 + 机位/运镜或转场 + 画面描述 + 动作/表演 + 环境运动及反馈**。

### 15秒示例结构

```
0-3s  ：开场建立（景别 + 入画 + 环境初态）
3-8s  ：发展/爆发（主体动作展开 + 运镜推进 + 核心事件）
8-12s ：高潮/转折（画面重心变化 + 关键动作/反馈）
12-15s：收束/落版（余波 + 环境回落）
```

> 这是 15 秒请求的示例骨架，不是默认时长，也不是模板。台词密度、动作节拍、情绪转折点决定实际切分，不要为了凑四段而拆。

### 每段必须描述的元素运动

| 层级 | 内容 | 示例 |
|------|------|------|
| 主体运动 | 角色动作、表情变化 | 主角迈步前行、汗水滑落、瞳孔收缩 |
| 环境运动 | 天空、云、光影、风 | 云层缓慢飘动、树叶摇曳、光影移动 |
| 背景运动 | 人群、物体、粒子 | 人群快速移动、落叶飘散、尘埃飞扬 |
| 特效运动 | 火花、雨滴、烟雾 | 火花飞溅、雨水顺着屋檐滴落、烟雾扩散 |

室外戏不得把天气停在名词层。风、雨、雪、雾或尘出现时，必须写它对人物衣发/皮肤/重心、场景植被/地面/水体、道具和光影中至少两类对象的可见作用，并保持方向、湿度与累积状态连续。细则见 `references/室外环境动力.md`。

### 错误格式（禁止）

❌ 缺少景别、❌ 缺少运镜/转场、❌ 缺少环境运动、❌ 时间段衔接方式不明

## 四、景别与运镜速查

### 景别

| 景别 | 画面范围 | 适用场景 |
|------|---------|---------|
| 远景 | 广阔空间，环境为主 | 开场建立场景、命运感 |
| 全景 | 人物全身 + 环境 | 展示人物与环境关系 |
| 中景 | 人物膝上 | 对话、双人动作 |
| 近景 | 人物胸上 | 表情变化、情绪传递 |
| 特写 | 面部/局部 | 关键情绪、证据、道具 |
| 主观视角 | 角色第一人称 | 沉浸感、紧张感 |

### 运镜/转场

| 方式 | 说明 | 情绪功能 |
|------|------|---------|
| 固定镜头 | 相机不动 | 压迫、观察、让表演发生 |
| 推镜头 | 相机向前 | 强调、心理压力增加 |
| 拉镜头 | 相机后撤 | 展示环境、孤立感 |
| 摇/移镜头 | 横向/纵向移动 | 展示空间、跟随 |
| 跟镜头 | 跟随主体移动 | 跟随运动、连续性 |
| 环绕 | 360度旋转 | 展示主体、被包围感 |
| 硬切 | 直接切换 | 节奏紧张 |
| 渐变 | 淡入淡出 | 情绪过渡 |
| 叠化 | 画面重叠 | 回忆、时间流逝 |
| 升格 | 慢动作 | 强调动作、情绪 |
| 降格 | 快动作 | 时间压缩 |

## 五、多模态引用语法

有资产图时的标准引用格式：

```
@图片1 作为角色固定形象参考，保持人物外貌、发型、服装一致
@图片2 作为场景固定参考，保持空间结构、色调、主要元素一致
@图片3 作为道具固定参考，保持材质、形制、尺寸一致
@视频1 参考运镜方式
```

> 音频参考位不用于配乐——本项目不输出 BGM。模型支持音频输入，但当前工作流不启用。

## 六、稳定性约束词库

> **这是词库，不是必写清单。** 真正每条都写的只有 `templates/标准输出模板.md` 里的通用六条。本节其余条目按场景取用，**与 skill 原始设计冲突时一律让位**——特效戏的空间异变本就要环境崩解，动作戏的手持震动本就要镜头抖，把这些约束硬加上去只会让效果被削平。

### 主体约束
`人物面部特征保持一致，不扭曲，不换脸，肢体比例自然`

### 场景约束
`背景环境保持稳定不闪烁/突变，场景元素位置固定，环境光照方向一致不跳变`

### 动作约束
`动作流畅连贯无卡顿/瞬移，肢体运动符合物理规律不反关节，动作幅度适中`

### 镜头约束

`镜头切换处角色形象、光位方向与色温、画面左右关系保持一致`

> 只管切点，不管镜头内怎么动。**不要补"摄像机运动平滑无抖动"**——手持震动、环绕、FPV、变速都是各 skill 明确推荐的手法，加了这句等于全部禁掉。也不要补"无跳切""构图主体位置一致"，那会与时间轴里的切镜指令正面冲突，导致景别全失效或切点换脸。

### 光影色彩约束
`光源方向和强度保持稳定，阴影投射方向一致，色彩风格统一无跳跃，画面曝光稳定无闪烁`

### 音频约束
`不输出背景音乐，画面不带字幕；角色台词正常出声，口型与台词严格对上`

> 「不输出BGM/字幕」只针对配乐和画面字幕条，**与角色说话无关**。台词必须出声且对口型，这是短剧的硬指标。

## 七、提示词字数约束

提示词写给 Seedance 2.0 视频模型，不是说明书也不是给人看的。每条文字最终输入模型时都必须有用。

| 场景复杂度 | 上限 |
|-----------|------|
| 简单戏（日常对话、单人物反应、固定场景） | ≤2000字 |
| 复杂戏（双人对峙、文戏推进、情绪变化） | ≤3000字 |
| 最复杂戏（特效爆发、多人混战、多段运镜混合） | ≤4000字 |

**统计口径：只算【素材引用】+【时间轴】两个区块，标点不计。**

固定约束与光影设计是每条都使用的结构信息，不计入本项目字数预算。画幅与时长没有独立输出区块。真正决定画面的是素材引用和时间轴，上限只管这两块。

### 上限是天花板，不是目标

这是**上限**，不是配额，更不是需要努力靠近的字数目标。判断标准永远是「这句话模型生成画面时用得上吗」——用得上就写，写完自然收尾，剩多少余量都不用管；用不上就删，哪怕远没到上限。

> 上限从 1000/2000/3000 上调到 2000/3000/4000，是因为原额度会挤压表演描写。多出来的额度**专款专用于表演层**（见下），不是拿去堆运镜、堆环境、堆形容词的。

### 预算分配（重点，别再写浅）

时间轴每一段的五件事里，**主体动作 = 动作 + 表演**，表演层不是可选项。常见的写坏方式是把预算全花在景别和运镜上，主体只剩一句"她神情复杂地看着他"——这种句子模型没法执行，等于白写。

| 层级 | 时间轴里的占比 | 说明 |
|------|--------------|------|
| 主体动作 + 表演 | **不少于一半** | 大动作 + 微表情 + 肢体潜意识动作 + 泄露点 |
| 景别 / 机位 / 运镜 | 约三分之一 | 够指明镜头怎么走即可，不铺陈 |
| 环境运动 / 光影变化 | 其余 | 只写会被看见的变化 |

**表演层的硬要求**（细则与词库见 `skills/情感表演.md`）：

- **每段主角必须有可执行的表演描写**，不能只写"情绪化地""神情复杂地""眼神一冷"这类抽象标签。抽象标签必须落到具体生理动作：眼睑、睫毛、视线落点、咬肌、喉结、呼吸、指尖、重心
- **情绪必须是动态的**：写"从什么状态变成什么状态、被什么触发"，不写静态的一个词。一段里至少有一次可见的表情演变
- **配得上景别**：特写和近景是给表演用的，切了特写却不写微表情，等于浪费镜头；远景大全景则不写微表情，写不到的东西写了也没用

**其余规则：**
- 不得为遵守字数而刻意缩写或省略必要信息导致画面质量下降
- 提示词中的每段文字都必须是 Seedance 2.0 模型生成画面时需要的指令
- 不写背景说明、设计意图、创作思路、前情摘要等模型不需要的内容
- **不写模型无法执行的技术参数**：帧数（"2-4帧微定格"）、帧率（"120fps"）、升格倍率（"20-30x"）都没有对应的控制接口，进了提示词就是无效 token。一律改写成视觉可判定的描述

## 八、提示词写作原则

| 原则 | 说明 |
|------|------|
| 目标导向 | 提示词是给模型的生产指令，不是设计说明。不写模型不需要知道的背景信息 |
| @引用优先 | 人物/场景/道具/运镜特征通过 @资产 引用传递，不由文字重复描述 |
| 一段只做一件事 | 单条提示词只负责一个片段的内容，不写"前情提要"或跨段总结 |
| 每个字必须有用 | 不写背景说明、设计意图、创作思路等模型不需要的内容 |
| 中文主干 | 主体描述一律中文；只有布光、运镜、材质、VFX 四类专业术语按「中文（English keyword）」附英文 |
| 只写可执行的 | 模型能生成画面的才写，帧率倍率之类的后期参数不写 |
