# 标准输出模板

> 全项目唯一输出格式。四个区块顺序固定，不增不减、不改名。
>
> 代码块内 = 直接投喂 Seedance 2.0 的内容，每个字都必须对生成画面有用。
> 代码块外 = 只写「输出备注」（拆条说明 / 删掉了哪条约束 / 待确认项），不进模型。

---

## 输出结构

````
【固定约束】
- 横屏真人电影写实风格，电影级画质，超细腻皮肤质感
- 不输出背景音乐，画面不带字幕；角色台词正常出声，口型与台词严格对上
- 角色面部特征保持一致，不换脸，不扭曲，肢体比例自然
- 背景环境稳定不闪烁
- 动作流畅连贯无卡顿无瞬移
- 镜头切换处角色形象、光位方向与色温、画面左右关系保持一致

【素材引用】
@[角色名] 作为角色固定形象参考，保持[服装/发型/配饰/体貌特征]一致
@[角色名2] 作为角色固定形象参考，保持[……]一致
@[场景名] 作为场景固定参考，保持[空间结构/主要陈设/色调]一致
@[道具名] 作为道具固定参考，保持[材质/形制/尺寸]一致

【光影设计】
- 主光方位：[顶光 / 侧光 / 逆光 / 伦勃朗光（Rembrandt lighting） / 底光]
- 光质：[硬光（hard light） / 柔光（soft light）]
- 光比：[低调照明（low-key, chiaroscuro） / 高调照明（high-key）]
- 动机光源：[烛火/月光/夕阳/壁灯/灵气光晕/林隙光/其他]
- 色调：[暖/冷/低饱和/冷暖对比]
- 主体-背景分离：[轮廓光勾勒（rim light） / 明暗反差 / 色彩对比]

【时间轴】
0-Xs：[景别]，[精确焦距 + 镜头类别 + 摄影机距离/透视结果]，[焦点/景深的可见结果]，[机位]，[运镜]，[节奏标注]。[主体动作与状态]。[客体动作，幅度受限]。[环境运动及其对人物、场景、道具和光影的作用]。[光影变化]。[角色]说："[台词]"

X-Ys：[景别]，[精确焦距 + 可见透视/景深结果]，[机位]，[运镜]，[节奏标注]。[主体动作与状态]。[客体动作]。[环境变化与人物/场景反馈]。[光影变化]。[角色]说："[台词]"

Y-Zs：[景别]，[精确焦距 + 可见透视/景深结果]，[机位]，[运镜]，[节奏标注]。[主体动作与状态]。[客体动作]。[环境变化与人物/场景反馈]。[光影变化]。[角色]说："[台词]"
````

**输出备注**（写在代码块外，不进模型）

- 拆条说明：[本场拆成几条、拆点在哪一镜]
- 删除的固定约束：[删了哪条、让位于哪个 skill 的什么手法]
- 待确认项：[资产占位需替换、脚本与资产冲突处、代做的导演判断]
- 时间轴工作基准：[仅当用户未指定总时长且要求先出时说明；不写进代码块]

## 各区块规则

### 【固定约束】

前六条为全项目通用，逐字照抄，不改写不精简。

第六条（镜头）只管**切点**：切换处保住人、光、左右关系。不要补写"摄像机运动平滑无抖动""无跳切""构图位置一致"——前者会压死手持震动、环绕、变速这些本就该用的运镜，后者会与时间轴里的切镜指令正面打架。

### 固定约束让位于 skill 原始设计（优先级规则）

**通用六条是防 AI 崩坏的底线，不是内容限制。** 当某条与 skill 里既有的手法冲突时，**以 skill 原始设计为准，把冲突的那条从本条提示词的固定约束里整行删掉**，并在代码块外注明删了哪条、为什么。

**不要两条都写。** 等权冲突进模型的结果不是各让一步，而是两边都失效——要么特效被削平，要么画面抖成一团。

常见让位场景（左列为通用六条里的原句）：

| 冲突的那条 | 让位于 | 处理 |
|--------|--------|------|
| 背景环境稳定不闪烁 | `特效戏.md` §3 空间异变、六大破界、§4 超现实拓扑 | 整行删除——环境崩解、折叠、明暗剧变是戏本身 |
| 不扭曲 / 肢体比例自然 | `特效戏.md` §4.3 人体解构、§2 变身类模板（爪纹、兽化、鳞甲） | 这两个分句一并删除，保留"不换脸"；限幻觉/法术场景 |
| 动作流畅连贯无卡顿无瞬移 | `特效戏.md` 模板D 时间冻结（对手被卡住）、身外化身；`动作戏.md` 模式B 瞬移连招 | 冻结段整行删除；模式B 已用轨迹可视化自解，通常不必删 |
| 镜头切换处画面左右关系保持一致 | 环绕运镜、群攻包围、长距离追逐、一镜到底调度 | 该分句删除 |

**已从通用条永久移除、不得回写的**：摄像机运动平滑无抖动、场景元素位置固定、肢体运动符合物理规律、画面曝光稳定无闪烁、摄影机不得越轴。这五条压死的分别是手持/环绕/变速运镜、空间异变、人体解构与变身、明暗剧变、群战环绕——全都是各 skill 明确推荐的手法。

判断标准就一条：**这条约束是在防模型崩坏，还是在防这场戏该有的效果？** 后者一律删。

**【固定约束】只有这六条，不再追加任何本条专属的锁定行或禁写行。** 站位、人数、道具身份、本场不该出现的元素，全部由【时间轴】的正面描写解决——写清这一段画面里有什么，比列一串"不许有什么"有效。

### 【素材引用】

**资产由用户提供，Agent 不自造。输出本区块之前必须先向用户索要过一次资产**（四类：场景 / 环境 / 人物 / 道具，流程见 `CLAUDE.md` 工作流程步骤 2）。三类资产**有则引用**：角色、场景、道具。

- **本条实际不涉及的类别整类省略。** 空庭对话没有关键道具就不写道具引用行——**不要为了凑齐三类而编一个道具资产出来**，那和"不自造"直接冲突。道具引用只给戏里真正被看到、被用到的那件
- 输出前先确认可用资产清单。用户未提供时，用 `@角色名` 占位，并在代码块外标注「需替换为实际资产名」。**不要因为没拿到资产就改走"在时间轴里展开完整外观描述"那条路**——那会吃掉一半字数预算，而你的工作流是先出资产图再生成视频，纯文生几乎用不到
- **有资产则简**：已挂资产图的对象，时间轴里只写当前镜头的动作、情绪、光线，**不重复描述五官、发型、服装形制、空间布局**

**每个资产一行，只写引用和要保持一致的属性，不在下方附加任何角色设定行。** 人物这一条戏怎么演，全部写在【时间轴】里。

### 【光影设计】

六项全填，不留空。动机光源必须是画面里真实存在的物件，且与资产一致——资产是壁灯就写壁灯，不能因为脚本写"烛火"就写烛火。

**场景资产图是本区块的第一依据，优先级高于脚本文字。** 有图就先从图里读四件事再落笔：实际灯具（决定动机光源）、窗门开口位置与朝向（决定主光方位、月光/日光能否打进来）、墙面帷幔木料地砖的固有色与反光率（决定色调与光比）、空间层次如屏风隔断廊柱（决定主体-背景分离手段）。没拿到图时按资产名写，并把"该场景实际光源是什么"列进代码块外的待确认项。

布光、运镜、材质、VFX 四类专业术语按「中文（English keyword）」格式写，其余一律纯中文。词条见 `references/镜头与灯光词典.md`。

### 【时间轴】

每段必须齐五件事：**景别/焦距/景深 + 机位/运镜 + 主体动作 + 环境运动及反馈 + 光影变化**。有台词则附在段末。

**焦距必须是精确值并写出可见结果：**

- 一镜只选一个全画幅等效焦距，不写 `24-35mm`、`85/100mm`、`或`、`任选`
- 大远景 / 远景 / 大全景可选 24mm、28mm、32mm 或 35mm，并写近机位、近大远小、背景更小更远、空间纵向延展等实际结果
- 全景只在明确交代全身关系或空间轴线时使用 65mm，并写中等机距、比例自然、空间轻压缩
- 中景 / 中近景 / 近景 / 特写 / 大特写 / 插入镜头使用 85mm 以上，优先 85mm、100mm 或 135mm；写远机位、背景相对放大靠近、前后景压缩、单一合焦平面和局部虚焦填充
- 用户明确指定焦距时优先遵从；焦距是创作意图，不把不可控的机身、光圈、帧率等参数写进生成提示词

- 一段只解决一个变化，不塞两件事
- 客体（对手、路人、陪体）动作幅度必须写限制，不得抢主体注意力
- 时间点连续无空档，末段写实际秒数（如 `10-15s`），不写 `Ends` 之类的占位词
- 时间轴按用户在生成界面选择的总时长编排，但代码块不单列画幅和时长字段；未给时长且用户要求先出时，按 15 秒内部工作基准编排并写在代码块外
- 单条超过模型单次生成上限时必须拆条，并在代码块外说明拆点
- 室外戏出现风、雨、雪、雾、尘或日照变化时，至少写环境本体和两类受影响对象：人物衣发/皮肤/重心，地面/植被/水体/帷幔，道具，光线/反射。写清触发、持续和回落；细则见 `references/室外环境动力.md`

**主体动作 = 动作 + 表演，表演层不是可选项。**

写坏的典型是预算全花在景别运镜上，主体只剩一句"她神情复杂地看着他"——模型执行不了，等于白写。规则：

- **表演篇幅不少于全段一半**。景别机位运镜约占三分之一，环境与光影占其余
- **抽象标签必须落到生理动作**："神情复杂""眼神一冷""情绪崩溃"都不合格，要写成眼睑、睫毛、视线落点、咬肌、喉结、鼻翼、呼吸、指尖、重心上的具体变化
- **情绪写成动态**：一段里至少有一次可见的表情演变，且写明被什么触发。不写静态的一个情绪词
- **配得上景别**：切了特写近景就必须写微表情，否则镜头白切；远景大全景不写微表情，看不见的写了也没用

词库与公式见 `skills/情感表演.md`（微表情公式 / 肢体落地感 / 泄露点），预算分配见 `references/Seedance规范.md` §七。

**台词写法：**

- 格式：`[角色]说："[台词原文]"`，写在该段末尾
- 台词**要出声**。「不输出背景音乐、画面不带字幕」指的是不要配乐、不要画面上的字幕条，跟角色说话无关
- 口型必须与台词对上，这是短剧的硬指标
- 语速需要特别控制时（急促/拖长/气声）在台词后补一句说明，不需要则不写
- 台词字数决定该段时长：慢速1秒2字 / 中速1秒3字 / 快速1秒4字，另加停顿与反应时间，标点不计

## 输出前自检

> **全项目唯一执行清单。** 各 skill 里的检查项只覆盖本领域特有的点，通用项以此处为准。

- [ ] **输出前是否已向用户索要过资产**（场景/环境/人物/道具），场景资产图是否问过；用占位是否因为用户明确说了没有
- [ ] 【光影设计】是否依据场景资产图写（有图时），而不是照脚本文字凭空布光
- [ ] 四个区块齐全、顺序正确、无【画幅与时长】区块
- [ ] 固定约束已按让位规则处理：不冲突的逐字照抄，**与本条 skill 手法冲突的整行删除**并在代码块外注明（特效戏尤其易漏）
- [ ] **【固定约束】是否只有六条**，有没有多写空间/人数/禁项之类的锁定行
- [ ] 戏里真正出现的资产是否都已引用；**有没有为凑齐三类而编造道具**
- [ ] 【素材引用】是否只有 @资产 引用行，有没有附加角色设定行
- [ ] 有资产的对象是否避免了外观重复描述
- [ ] 脚本与资产冲突处是否已按资产写，并在代码块外列了待确认
- [ ] **每段主角是否都有可执行的表演描写**，有没有残留"神情复杂""眼神一冷"这类抽象标签
- [ ] 表演层篇幅是否不少于该段的一半，情绪是否写成了带触发点的动态演变
- [ ] 特写/近景段是否写了微表情；远景大全景段是否误写了看不见的微表情
- [ ] 时长与台词字数是否对得上（标点不计）
- [ ] 每段是否写了单一精确焦距，并给出与景别相符的摄影机距离、透视和景深可见结果
- [ ] 每段是否齐了景别/焦距/景深、机位/运镜、主体、环境及反馈、光影五件事
- [ ] 室外天气是否真实作用到人物、场景/道具和光影，而不是只写一个天气名词
- [ ] 是否为中文主干，只在布光/运镜/材质/VFX 四类术语后附英文
- [ ] 是否混入了模型无法执行的参数（帧数、fps、升格倍率、分辨率等技术参数）
- [ ] 代码块内是否混入了设计意图、前情摘要等模型不需要的内容
- [ ] 拆条说明、删除的约束、待确认项是否写在代码块外
- [ ] 字数在限内（**只统计【素材引用】+【时间轴】**：简单≤2000 / 复杂≤3000 / 最复杂≤4000）。上限是天花板不是目标，没写满不用补
